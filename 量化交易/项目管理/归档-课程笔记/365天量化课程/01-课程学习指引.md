# 365 课程学习指引

课程的唯一浏览入口是[课程大纲与本地映射](../../../../pam-video-captures/365-days-quant-finance/knowledge-map.html)。该页面按官方大纲的 11 个阶段、365 节组织，每节课卡片直接进入本地整理好的图文口播页；有 Python 实操的课次同时挂 Notebook 与静态报告入口。本节点说明**怎么用这个入口学**，不复制其内容。

## 入口页面提供什么

| 区块 | 内容 | 学习用途 |
|---|---|---|
| 阶段导航 | P1–P11 快速跳转，每阶段标注课数、本地整理数、大纲上线数 | 判断当前学到哪、哪些还没采集 |
| 课程卡片 | 大纲标准标题 + 本地视频题名 + 状态 | 用标准标题理解知识点，营销式视频标题只作辅助 |
| 图文口播页 | 课件截图与对应口播逐段配对，另附内容摘要 | 主学习界面：读摘要抓主线，读逐段核对细节 |
| 模块区块 | P1-M1–M6 / P2-M1–M6 模块说明与 L1–L6 综合实验合并呈现 | 学完一个模块做一次综合实验，检验是否真的连起来了 |
| Notebook 与报告 | 逐课实验的 `.ipynb` 与静态 HTML | 报告用于快速回顾，Notebook 用于动手改参数 |

## 单节课的学习动作

1. **先读摘要**：每集 `summary.md` 固定四段——本集主线、关键概念与计算、方法边界、对量化项目的价值。先读这四段建立预期。
2. **再看图文口播**：带着预期扫课件截图，只在概念没懂的地方读对应口播原文。不必逐段通读。
3. **有实操就跑 Notebook**：改参数、改标的，观察结论是否稳定。跑不通先查环境（`pkm-quant`），不要误判为原理错误。
4. **记边界不记结论**：课程的简化假设（不含手续费、固定年化天数、单一样本区间）要显式记下来，这些是后续被推翻的地方。

## 阶段与模块的学习节奏

- **P1（1–30）量化基础**：反向设计——第 29 课策略报告是产物，第 30 课能力矩阵是验收，前 28 课都在为报告的某个判断提供证据。学的时候常问：这一课支撑报告的哪一节？要点见 [P1 量化基础要点](node:c365p1)。
- **P2（31–60）Python 工具栈**：重点不是语法，是同一个工具在金融时间序列中的数据语义和失效边界。要点见 [P2 工具栈要点](node:c365p2)。
- **P3（61–90）数据与因子工程**：当前阶段。按主题簇推进（数据质量与口径 61–66、因子图谱 67–76、因子处理与检验 77–82、组合与多因子 83–89），学完一簇沉淀一批笔记。
- **P4 起**：大纲已上线但本地尚未采集，进度以入口页面的实际状态为准。

## 使用这套材料时的三条纪律

1. **课程观点不等于项目结论**：未经代码或一手资料验证的说法标为「课程观点」，不直接写进自有体系。
2. **以本地整理状态为准**：大纲标记「已上线」与本地「已整理」是两个状态，入口页面不会把未采集的课程标为完成；第 82 课源视频与标题冲突、第 90 课尚未发布，均已隔离。
3. **字幕仍是机器转写稿**：本地 Whisper 转写并做过金融术语校订，但未逐句人工听校；关键数字和公式以 Notebook 运行结果为准。

## 材料维护边界

课程素材包（视频、字幕、截图、摘要、入口页面）由采集流水线维护，本知识库只读引用，分工见项目管理中的协作契约。两个项目必须保持兄弟目录，否则入口页面与实验报告之间的相对链接会失效。
