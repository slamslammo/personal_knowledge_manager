### 已完成：理论原点实验

- 使用 20,000 条、每条 252 步的独立高斯增量路径，验证相邻增量相关接近 0、方向接近各半、累计方差随期限线性增长。
- 在 52% 胜率、等额赔率下推导凯利比例为 4%，并用 50,000 个终值路径比较半凯利、全凯利、双倍凯利和 10% 过度下注。
- 10% 仓位的理论期望财富为 54.164，但模拟中位财富只有 0.364，约 63.99% 路径低于本金，验证“正算术期望不等于典型路径长期增长”。
- 代码：`实验/scripts/task2_theory_origins.py`；报告：`实验/reports/Task2-理论原点实验.md`。
- 稳定结论已拆分到 `知识库/04-数据与收益/05-随机游走与布朗运动.md` 和 `知识库/07-风险与组合/06-概率优势与凯利仓位.md`。

### 必须掌握

1. **量化的定义**：用数据、规则和可重复计算辅助金融分析、交易与风险管理，不是凭感觉猜涨跌。
2. **研究四步闭环**：提出假设 → 把自然语言变成可计算条件 → 用历史数据验证 → 形成规则并继续迭代。
3. **基础运行流程**：获取数据 → 分析数据 → 设计策略 → 回测 → 模拟交易；知道每一步的输入与输出。
4. **概率思维**：量化寻找的是统计优势和正期望，不是单次必胜。随机性、仓位与长期重复共同决定结果。
5. **Python 工具分工**：NumPy 做数值与随机模拟，pandas 处理表格和时间序列，Matplotlib 画图，yfinance / AkShare 获取行情，Jupyter 承载代码、结果和说明。
6. **真实数据最小能力**：能下载或读取一只股票的价格与成交量，识别日期、收盘价、成交量，并画出基本走势图。

### 需要建立直觉，但暂不要求深入

- 随机游走和布朗运动用于说明短期价格具有显著随机性；本任务不要求掌握随机微分方程。
- 索普实验用于说明“微小概率优势 + 合理仓位 + 长期纪律”；凯利公式的推导和实际资产配置留待后续。
- Python 与其他语言的比较、人物和年份用于背景理解，不是本阶段记忆重点。
- AI 可以辅助学习、写代码和整理思路，但模型输出不能作为投资决策或回测证据。

### 需要特别校正的表述

- “量化不预测未来”是入门教学中的简化表达。更准确地说，量化不做确定性预言，而是估计条件概率、期望收益或风险，并检验这种估计能否转化为成本后的策略价值。
- 随机游走是基础模型，不等于所有市场、所有周期都完全不可预测。
- 历史回测发现规律不代表未来继续有效，还需要交易成本、样本外验证和风险约束；这些内容在后续节点展开。
