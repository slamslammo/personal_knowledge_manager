# P1 课程辅助设计

## 1. 定位

P1 覆盖《365 天量化金融》第 1–30 课。它不是金融理论词条集合，而是一条可审计的策略研究证据链：

> 交易想法 → 可证伪的市场假设 → 数据契约 → 收益、风险与基准 → 统计证据 → 成交、成本与可执行性 → 策略研究报告 → 阶段验收。

第 29 课的策略报告是阶段产物，第 30 课的能力矩阵是阶段验收。第 1–28 课均需说明自己为报告中的哪个判断提供证据。

## 2. 与 P2 的边界

- P1 解释金融概念、公式、研究用途、结果含义和失效边界。
- P2 解释 Python API、数据结构、shape/axis、性能、复现和工程质量。
- P1 可以使用 NumPy、Pandas、SciPy、statsmodels 等工具，但不重复 P2 的 Python 入门教学。
- P1 Notebook 首次出现的金融计算必须透明展开；通用实现可以复用 `src/`，但不能用封装遮蔽时间对齐、基准、成本或未来信息。

## 3. 稳定设计决策

1. **官方课程编号是主键**：页面仍按第 1–30 课排列，自定义模块只负责说明课程对研究闭环的贡献。
2. **反向设计、顺序呈现**：先固定第 29 课报告字段和第 30 课验收矩阵，再建设第 1–28 课；页面不改变官方顺序。
3. **唯一入口**：`pam-video-captures/365-days-quant-finance/knowledge-map.html` 是唯一浏览器入口，不建立第二套课程首页。
4. **模块与实验合并**：P1-M1–M6 与 P1-L1–L6 在同一个模块头呈现，沿用 P2 已确认的交互。
5. **每课都有知识讲解**：第 1–30 课均有静态 HTML；有大纲 Python 实操的课程同时提供 Notebook。
6. **不制造无价值 Notebook**：第 1–3、25、30 课以知识讲解、对照表或能力矩阵为主；其余 25 课提供 Notebook。
7. **数据默认离线**：真实接口与研究计算分离。Notebook 默认使用可复现教学快照，联网获取只作为显式可选步骤。
8. **数据身份显式**：页首标注真实、模拟或脱敏；记录来源、标的、日期、频率、时区、复权、生成方式和 `as_of`。
9. **先手算、后完整数据**：公式先使用可核对的小例子，再进入行情、期权或订单簿场景。
10. **结果必须可解释**：输出不仅展示数值，还要说明金融含义、单位、假设和不能推出的结论。
11. **统计显著不等于经济有效**：同时报告效应大小、样本外表现、基准、成本和稳健性。
12. **回测结果不等于可交易收益**：信号时点、下单时点、成交规则、费用、滑点、冲击和容量必须分开说明。
13. **定价模型不等于预测模型**：风险中性概率、Black–Scholes 和 Greeks 的定价/对冲用途与真实世界预测严格分开。
14. **知识讲解可追溯**：课程原始图文口播、整理后的定义、公式、数据、Notebook、综合实验和报告字段形成可核对映射。
15. **不先做泛化节点图谱**：P1 第一版采用研究证据链和能力矩阵；节点式图谱后续作为辅助查询，不替代课程与研究流程。

## 4. 六个模块

| 模块 | 课程 | 研究贡献 | 综合实验 |
|---|---:|---|---|
| M1 研究问题与市场假设 | 1–4 | 明确交易对象、市场机制、策略类型和优势来源 | L1 研究假设卡 |
| M2 收益、时间价值与风险 | 5–8 | 建立收益、复利、波动、协方差和相关性的统一口径 | L2 收益—风险账本 |
| M3 统计证据与可预测性 | 9–16 | 区分相关、解释、预测与统计证据 | L3 信号证据审计 |
| M4 随机模型与衍生品风险 | 17–21 | 区分模拟、预测、定价和对冲 | L4 随机场景与期权风险 |
| M5 市场微观结构与执行 | 22–25 | 把理论收益还原为订单、成交、成本和场所规则 | L5 执行可行性与成本 |
| M6 数据契约与策略报告 | 26–30 | 固定数据口径，完成研究报告与能力验收 | L6 数据契约与策略报告 |

## 5. 逐课知识讲解模板

每课依次包含：

1. 课程定位与原始材料。
2. 本课为策略报告解决的问题。
3. 中文名称、英文名称、缩写和准确定义。
4. 公式、符号、单位和成立条件。
5. 可手工核对的小例子或机制图。
6. 课程代码或交互实验。
7. 输出的金融含义。
8. 常见误读、失败示例和方法边界。
9. 对应的策略报告字段与 P2 工具课程。
10. 阶段验收问题。

Notebook 中的代码遵循 P2 已确认的表达规范：

> 方法与参数说明 → 单一概念代码块 → 带标签或确定值输出 → 量化意义与边界。

代码块顶部用一句话说明目的；只有切片、关键轴、交易时点或可直接核对的小数组使用行尾注释，避免逐行注释淹没逻辑。

## 6. 第 29 课策略报告

固定报告结构：

1. 研究问题与可证伪假设。
2. 市场、资产范围和交易约束。
3. 数据来源、字段、时间、复权和频率。
4. 信号、仓位、调仓与成交规则。
5. 策略收益、累计净值和基准。
6. 波动、最大回撤、Beta 与尾部风险。
7. 统计检验、效应大小和样本外结果。
8. 手续费、滑点、市场冲击和容量假设。
9. 参数敏感性、未来信息和适用边界。
10. 研究结论与下一步验证计划。

## 7. 第 30 课能力矩阵

每项能力采用五级验收：

1. 能准确解释。
2. 能手工计算或画出机制。
3. 能用代码复现。
4. 能识别数据、统计、成本和模型边界。
5. 能写入完整策略报告。

课程中的十项核心能力按以下链路追踪：

> 概念 → 公式 → 数据字段 → 课程 → Notebook → 综合实验 → 报告章节。

## 8. 环境与数据

- 环境：沿用 `pkm-quant`，Python 3.11。
- 依赖：NumPy、Pandas、Matplotlib、SciPy、statsmodels、scikit-learn、Jupyter、nbclient；不为 P1 新建环境。
- 教学数据：多资产日线、基准指数、期权参数、订单簿/逐笔成交、公司行动和多频率行情。
- 数据接口：yfinance、AkShare、Tushare 只放在适配层；Notebook 默认读取离线快照。
- 复现要求：固定随机种子，记录时区、交易日、年化常数、复权和成本口径。

## 9. 验收

- 第 1–30 课均有知识讲解 HTML。
- 大纲中 25 个 Python 实操课程均有 Notebook，且 `Restart Kernel and Run All` 通过。
- P1-L1–L6 综合实验全部可运行或可交互。
- 第 29 课能生成策略报告 HTML；报告包含收益、风险、成本和基准。
- 第 30 课能力矩阵能回链课程、实验和报告字段。
- 默认离线执行，无隐藏执行顺序依赖。
- 公式由小样本断言核验；图表标题、坐标轴、图例和单位完整。
- 不保留未解释的 Warning/Traceback。
- 真实、模拟、脱敏数据标识清楚。
- `knowledge-map.html` 无失效本地链接，不保留第二套入口。

## 10. 迭代规则

- 每批开发前在 `迭代记录.md` 记录范围、产物和设计变化。
- 稳定决策发生变化时，先更新本文件，再批量修改课程。
- `artifact-manifest.json` 是课程与产物映射的机器可读依据。
- 构建与验收脚本保留在 `tools/`，不只保留结果文件。
