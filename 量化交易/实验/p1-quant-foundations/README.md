# P1：量化基础

本项目承接《365 天量化金融》第 1–30 课，把课程材料转化为“研究证据链 + 可运行实验 + 策略报告 + 能力矩阵”。

浏览器唯一入口：

- [365 天量化金融课程学习整理](../../../../pam-video-captures/365-days-quant-finance/knowledge-map.html#P1)

项目依据：

- [课程辅助设计](课程辅助设计.md)
- [迭代记录](迭代记录.md)
- [课程产物映射](artifact-manifest.json)
- [Notebook 执行验收](notebook-validation.md)
- [入口与产物验收](artifact-validation.md)

目录：

- `notes/`：非 Notebook 课程的知识讲解源文件。
- `notebooks/`：逐课金融概念与研究实验。
- `labs/`：六个模块综合实验。
- `reports/`：浏览器可读静态报告。
- `data/fixtures/`：离线教学数据。
- `src/`：跨课复用的透明计算函数。
- `tools/`：批量构建、导出和验收。
- `outputs/`：实验结果和策略报告。

环境沿用 `pkm-quant`，不单独新建 P1 环境。
