# Quant-for-Beginners 课程映射

| 课程内容 | 知识节点 | 实验承接 |
|---|---|---|
| 第 1 章：什么是量化金融 | 量化研究框架、随机游走与布朗运动、概率优势与凯利仓位 | 巴舍利耶随机游走与索普仓位模拟、真实行情获取 |
| 第 2 章：第一个量化实验 | OHLCV、收益率与净值 | 数据检查、收益率计算与可视化 |
| 第 3 章：移动平均线策略 | 趋势与移动平均线、信号与仓位 | MA5/MA20 信号和调仓记录 |
| 第 4 章：策略回测 | 信号时序、基准、绩效指标 | 最小回测与买入持有比较 |
| 第 5 章：理解波动率 | 波动率 | 日波动和年化波动比较 |
| 第 6 章：Sharpe 与 Beta | Sharpe 与 Beta | 风险收益散点与市场敏感度 |
| 第 7 章：最大回撤与仓位 | 最大回撤与仓位管理 | 水下曲线与不同仓位对比 |
| 第 8 章：多标的与相关性 | 相关性、组合构建 | 相关矩阵、等权组合和再平衡扩展 |

课程当前用于建立直觉。完成基础复现后，应补交易成本、数据偏差、样本外验证和运行约束，使结果从教学示例走向规范研究。
