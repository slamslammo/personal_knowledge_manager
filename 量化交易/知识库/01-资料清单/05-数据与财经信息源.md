# 数据与财经信息源

当前优先级低于课程、实验和工具选型。本页先建立一手来源入口，不建设实时新闻聚合系统。

## A 股与中国宏观的一手入口

| 来源 | 主要内容 | 后续用途 |
|---|---|---|
| [上海证券交易所](https://www.sse.com.cn/) / [深圳证券交易所](https://www.szse.cn/) / [北京证券交易所](https://www.bse.cn/) | 交易规则、上市公司、公告、行情和指数说明。 | 核验 A 股交易机制、停复牌、涨跌幅和市场规则。 |
| [巨潮资讯](https://www.cninfo.com.cn/) | 上市公司法定信息披露。 | 构建以真实披露日为准的 point-in-time 财务事件。 |
| [中国证监会](https://www.csrc.gov.cn/) | 法规、政策、行政许可和监管信息。 | 核验制度变化，不依赖媒体转述。 |
| [中国金融期货交易所](https://www.cffex.com.cn/) | 股指期货、国债期货、期权的合约和交易数据。 | 衍生品、套保、基差和合约规则研究。 |
| [中国人民银行](https://www.pbc.gov.cn/) / [国家统计局](https://www.stats.gov.cn/) | 货币政策、利率、金融统计和宏观指标。 | 后续宏观因子和市场状态研究。 |

## 海外与研究资料

| 来源 | 主要内容 | 后续用途 |
|---|---|---|
| [SEC EDGAR](https://www.sec.gov/edgar/search/) | 美股公司原始申报文件。 | 核验 yfinance 等接口之外的公司事件和披露时间。 |
| [FRED](https://fred.stlouisfed.org/) | 美国及国际宏观时间序列。 | 利率、通胀、信用和流动性因子。 |
| [SSRN Financial Economics](https://www.ssrn.com/index.cfm/en/fen/) | 金融经济工作论文。 | 查找策略、因子、回测与风险研究的原论文。 |
| [arXiv Quantitative Finance](https://arxiv.org/archive/q-fin) | q-fin 分类预印本。 | 跟踪新方法；预印本不等同于经过同行评议。 |

## 接口不是原始来源

| 接口 | 作用 | 必须补记的信息 |
|---|---|---|
| [AkShare](https://github.com/akfamily/akshare) | 聚合多个公开站点，方便研究 A 股、港美股、基金、期货和宏观数据。 | 具体函数的底层站点、字段、单位、复权、更新时间和接口变更。 |
| [yfinance](https://github.com/ranaroussi/yfinance) | 方便获取 Yahoo Finance 可见的数据。 | 非 Yahoo 官方 SDK；记录版本、请求时间、调整参数和限流情况。 |
| Qlib 数据工作流 | 把原始数据转成统一研究格式。 | 原始数据源、股票池历史、复权因子、缺失值和披露时点。 |

## 数据沉淀最小记录

每份正式实验数据至少记录：来源页面或接口、访问日期、市场和标的、开始结束日期、频率、时区、价格和数量单位、复权口径、公司行动、缺失处理、是否包含退市样本、许可证或使用限制。

财经新闻和分析系统以后再建立。届时先接公告、监管、公司原始披露和宏观发布，再引入媒体摘要；AI 摘要只能作为检索入口，不能替代原文和事件时间戳。
