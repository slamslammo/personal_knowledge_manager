# 365 天量化课程

## 在本项目中的定位

[Bilibili 课程入口](https://www.bilibili.com/video/BV1yR9qBUE7w/)符合当前“有交易经验，在实践中补理论”的路径，因此从普通参考资料提升为中文理解主线。它和 Datawhale 的关系是互补：视频负责连接真实交易问题，Notebook 和本项目实验负责验证。

课程当前已经形成四段内容：

| 当前集数 | 内容重心 | 对本项目的价值 |
|---|---|---|
| 01–30 | 金融资产、收益、风险、概率、衍生品、微观结构、交易成本 | 把炒股经验转成可讨论、可计算的概念。 |
| 31–60 | Python、NumPy、pandas、数据、可视化、数据库、测试、Git、Docker | 建立研究工具链和工程习惯。 |
| 61–66 | 数据清洗、复权、因子对齐、未来函数和 point-in-time | 直接提高回测可信度。 |
| 67–74 | 价值、成长、质量、动量、反转、低波、规模等因子 | 进入 Qlib 和截面研究前的概念入口。 |

## 后续归档方案

后续获得明确授权并开始归档时，复用机器学习视频笔记的结构，但增加来源和版权边界：

```text
资料/量化金融365/
├── metadata.json                 # 集数、标题、URL、发布日期、时长、来源状态
├── README.md                     # 归档范围、用途和更新方式
└── episodes/
    └── 01_量化路线图/
        ├── 来源与学习记录.md
        ├── selected_frames/      # 只保留表达关键概念的画面
        └── 量化金融365笔记.html  # 转写、图片、论证、实验和延伸链接
```

处理顺序：

1. 先建立全部已发布课程的元数据清单，不获取媒体文件。
2. 对每集做模拟探测，记录公开视频、官方字幕、音视频格式和不可用原因。
3. 优先使用作者公开的 YouTube 内容；Bilibili 付费内容只在用户合法访问范围内使用，不绕过付费或复制访问凭据。
4. 有字幕先校对字幕，无字幕再做语音转写；转写不是最终笔记。
5. 按概念切换选择关键帧，避免按固定时间间隔堆图。
6. 把视频主张与一手文档、免费教材、论文和代码实验交叉验证。
7. 最终材料仅用于个人学习，不发布或分发课程视频、完整课件和大段逐字稿。

## 单集沉淀标准

每集只记录五类内容：作者的关键主张、与真实交易的连接、公式或代码、证据与反例、进入知识地图的位置。没有经过验证的观点标为“课程观点”，不能直接写成项目结论。
