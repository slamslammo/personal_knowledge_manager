# 数学基础与量化

## 定位

数学不作为开始量化实践前必须学完的前置课程，而是在研究问题出现时提供解释工具。本项目当前只保留三个经过确认的入口：看见统计、Visualize-ML 和 QuantEcon。

```text
量化问题
   ├── 概率、分布、推断不直观 ──→ 看见统计
   ├── 需要公式、图解或 Python ──→ Visualize-ML
   └── 进入随机过程与经济模型 ──→ QuantEcon（暂存观察）
```

## 1. 看见统计：当前首选入口

[看见统计·中文版](https://seeing-theory.brown.edu/cn.html)是面向概率统计的中文交互网站，源代码位于 [seeingtheory/Seeing-Theory](https://github.com/seeingtheory/Seeing-Theory)。它通过可操作图形解释六组内容：

| 模块 | 量化中的连接 |
|---|---|
| 基础概率：随机事件、期望、方差 | 期望收益、收益方差、盈亏概率。 |
| 进阶概率：集合、古典概型、条件概率 | 条件信号、胜率、贝叶斯更新。 |
| 概率分布：随机变量、离散与连续分布、中心极限定理 | 收益分布、抽样误差、聚合收益。 |
| 频率派推断：点估计、置信区间、Bootstrap | 策略指标不确定性、因子收益置信区间。 |
| 贝叶斯推断：先验、似然、后验 | 根据新信息更新策略或市场状态判断。 |
| 回归分析：最小二乘、相关性、方差分析 | Beta、因子暴露、相关性与回归诊断。 |

使用方式：先操作图形并用自己的话解释变量变化，再用量化实验的数据重画对应图表。它解决直觉问题，不单独承担严谨推导和时间序列验证。

## 2. Visualize-ML：共同数学底座

[Visualize-ML](https://github.com/Visualize-ML)提供中文全彩图解、分章 PDF 和大量 Python/Jupyter 示例，适合作为机器学习和量化交易共用的数学资料库。当前只建立以下映射：

| 项目 | 建议章节 | 量化用途 |
|---|---|---|
| [《数学要素》](https://github.com/Visualize-ML/Book3_Elements-of-Mathematics) | 函数、导数、偏导、微分、积分、优化入门、概率与统计入门。 | 连续复利、边际变化、梯度、损失函数和最优化。 |
| [《矩阵力量》](https://github.com/Visualize-ML/Book4_Power-of-Matrix) | 向量与矩阵、投影、矩阵分解、特征值、SVD、拉格朗日乘子、数据分解。 | 协方差矩阵、因子暴露、PCA、风险模型和带约束组合优化。 |
| [《统计至简》](https://github.com/Visualize-ML/Book5_Essentials-of-Probability-and-Statistics) | 分布、条件概率、高斯分布、协方差矩阵、蒙特卡洛、统计推断、贝叶斯、回归、PCA。 | 收益与风险分布、模拟、估计误差、因子检验和降维。 |

使用顺序不是 Book 3 → Book 4 → Book 5。遇到问题后直接进入相应章节：

- 不理解概率或估计含义：先看见统计，再查《统计至简》。
- 不理解协方差、投影或 PCA：查《矩阵力量》，再回到《统计至简》的应用章节。
- 不理解梯度、目标函数或约束：查《数学要素》和《矩阵力量》的优化相关章节。
- 需要验证：运行仓库对应章节的 Notebook，并换成收益率、因子或组合数据。

## 3. QuantEcon：先登记，暂不设学习路线

[QuantEcon](https://quantecon.org/)聚合了开源 Python/Julia 讲义、书籍和代码库，其中 [Quantitative Economics with Python](https://python.quantecon.org/)涉及概率、马尔可夫过程、动态规划、经济模型与资产定价。

它与量化的潜在连接较强，但内容以经济学模型为主、跨度和难度较大，目前还不能确定哪些章节最适合本项目。因此当前状态为“已发现、待映射”，不列入近期学习任务。

后续只有在以下问题出现时再评估：

- 市场状态转移和马尔可夫模型；
- 随机贴现、资产定价和风险中性概率；
- 动态资产配置或最优停止；
- 需要把经济机制写成可运行 Python 模型。

评估时记录“问题 → 具体讲义 → 最小代码实验”，不以浏览完整网站作为完成标准。

## 暂不扩展

本节点暂不加入数学视频、更多英文教材、资源大全或面试题仓库。先观察以上材料在真实学习中的命中率；只有现有三类入口无法解释具体问题时，才补充新来源。
