# 量化学习路线图

本板块当前处于**广度学习期**：以两门主线课程为组织骨架，学到哪、知识长到哪，先完成第一轮螺旋，再自下而上重构自有体系。整体分四个阶段：

| 阶段 | 内容 | 状态 |
|---|---|---|
| 1. 课程承载 | 结构以两门课程为主体，资料与环境就位 | ✅ 本结构即产物 |
| 2. 广度学习 | 每门课按「原材料 → 章节要点 → 课程知识网络」推进 | 🔄 进行中 |
| 3. 融会贯通 | 两轨知识点去重合并，重构自有量化体系 | 待启动，见[体系蓝图](node:blueprint) |
| 4. 实践闭环 | 基于自有体系开展研究实验 | 规划中 |

## 两条课程主线

- **[365 天量化课程](node:c365overview)**：中文视频主线，11 阶段 365 课。本地已整理 88 课；P1 量化基础、P2 工具栈已完成学习整理并各有 30 余个可运行实验；P3 数据与因子工程学习中。
- **[Datawhale quant-for-beginners](node:dwqoverview)**：Notebook 实践主线，8 章。第 82 期组队学习进行中，已完成环境搭建与第一章理论原点实验。

两轨共用同一个开发环境 `pkm-quant`（见[实验环境](node:env)），后续自有体系的实验也在该环境进行。

## 怎么读这张地图

- 首页网络图：每层一条学习轨，实心节点已成文、虚线节点待蒸馏，曲线是节点互引。
- **跨轨连线是阶段三的关键信号**：两门课讲到同一概念时，节点间会累积互链；连线密集处就是将来去重合并的候选。
- 逐课进度记录在项目管理的课程学习台账中，知识节点只承载稳定的结论，不承载学习状态。
