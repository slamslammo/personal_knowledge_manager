# 量化交易

这是 `personal_knowledge_manager` 的第三个知识管理板块。当前处于广度学习期：知识库以两条课程主线组织，学到哪、知识长到哪；第一轮课程学完后，再自下而上融合为自有量化体系（见知识库「体系蓝图」节点）。

当前由两条互补入口共同推进：Datawhale 与 Yibo 维护的 [quant-for-beginners](https://github.com/datawhalechina/quant-for-beginners) 负责 Notebook 实践；[365 天量化课程](https://www.bilibili.com/video/BV1yR9qBUE7w/) 负责把金融、交易经验、数据、工程和因子概念串起来。知识库按稳定的量化研究框架组织，不复制任一课程目录，也不要求学完全部理论才开始实验。

> 本板块仅用于学习与研究，不构成任何投资建议。历史数据和回测结果不能保证未来表现。

## 阅读入口

下载仓库后，直接用浏览器打开：

[知识地图.html](知识地图.html)

该 HTML 使用本目录内的相对路径引用内容和图片，不依赖作者本机的绝对路径。内部知识链接使用 `#node=...` 静态路由，可用浏览器前进和后退在节点间切换。

首页是分层知识网络：每一层对应研究闭环的一个阶段，实心节点已成文、虚线节点为提纲，节点间曲线为正文互引（由 `build.py` 从 `node:` 链接自动抽取）。悬停查看关联，点击进入正文；每篇正文文末附「本文引用 / 被引用」双向关联。

> 公式渲染依赖联网加载 MathJax CDN。离线打开时正文与图片正常显示，数学公式会暂时呈现为 LaTeX 源码。

## 板块定位

学习按四个阶段推进：课程承载 → 广度学习 → 融会重构 → 实践闭环。当前在阶段二，知识库结构与之对应：

```text
🎓 365 天量化课程     11 阶段 365 课，概念证据链主线；P1/P2 已完成要点综述，P3 学习中
🐣 Datawhale 量化入门  8 章 Notebook 实践主线；第 82 期组队学习进行中
🔬 实践与环境          pkm-quant 统一环境与实验规范，两门课与自有研究共用
🧩 体系蓝图            阶段三重构的输入：研究闭环骨架与九章大纲草案
```

每门课按「原材料 → 章节要点 → 课程知识网络」推进：课程素材由采集流水线整理（见协作契约），学完一个主题簇就把结论蒸馏为知识节点；两门课讲到同一概念时节点互链，跨轨连线密集处即阶段三的去重合并候选。

## 目录结构

```text

├── README.md
├── 知识库/          # 内容源头：一个知识点一个 md

├── build.py         # 生成 HTML 阅读视图
```

## 维护方式

修改 `知识库/` 后，在本目录运行：

```bash
python3 build.py
```

每个知识节点负责解释“为什么”和“概念如何连接”；`实验/` 负责用同一份数据、代码和输出验证“如何计算、如何观察”。上游课程 Notebook 不直接复制进仓库，实验以自己的问题、代码、观察和结论重新组织。
