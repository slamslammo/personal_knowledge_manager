# 资料清单

> 资料分为中文体系与英文体系。两套材料都可以作为机器学习主线,差别主要在语言成本、讲解风格和实践侧重点。阅读时按自己的理解成本选择入口,再用另一套材料对照补足。

## 资料说明

不同资料会重复讲线性模型、SVM、树模型、聚类和降维,但各自承担的问题不同:

- 西瓜书 / ISLP：这个模型在机器学习体系中解决什么问题。
- 南瓜书 / MML / CS229：公式来源、推导依据与关键中间步骤。
- 李航：模型、策略、算法如何严谨对应。
- Datawhale toy code / Hands-On ML / sklearn / mlcourse.ai：如何把模型放进可运行的训练、评估和调参流程。
