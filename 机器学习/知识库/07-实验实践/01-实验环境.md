# 实验环境

## 推荐选择

机器学习实验环境使用 Miniforge + 独立 conda 环境，当前环境名为 `pkm-ml`。

不使用完整 Anaconda 作为项目默认方案。

原因:

- Miniforge 默认使用 `conda-forge`，依赖来源清晰，适合开源项目复现;
- 安装体积更小，不会一次性安装大量暂时不用的包;
- 每个项目独立环境，避免本机不同 Python 和 pip 之间互相干扰;
- 机器学习实验以 `numpy`、`pandas`、`scikit-learn` 为主，Mac 本地 CPU 足够。

## 环境创建

```bash
conda env create -f environment.yml
conda activate pkm-ml
python -m ipykernel install --user --name pkm-ml --display-name "Python (pkm-ml)"
```

如果本机安装了 `mamba`，也可以用:

```bash
mamba env create -f environment.yml
```

## 使用规则

进入项目实验前先激活环境:

```bash
conda activate pkm-ml
```

激活后统一使用:

```bash
python --version
python -m pip --version
python -m pip install xxx
```

不要在项目环境里直接依赖全局 `python3`、`pip3` 的指向。`python -m pip` 可以保证 pip 安装到当前激活环境对应的 Python 里。

Notebook 中选择内核 `Python (pkm-ml)`。

## 当前配置

`pkm-ml` 使用 Python 3.11，核心依赖包括:

- `numpy`、`pandas`、`scipy`;
- `matplotlib`、`seaborn`;
- `scikit-learn`;
- `jupyterlab`、`ipykernel`。

后续如果进入 PyTorch、CNN、Transformer 实验，再单独建立深度学习环境，不要提前把机器学习环境做重。
