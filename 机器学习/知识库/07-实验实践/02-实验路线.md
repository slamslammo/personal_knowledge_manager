# 实验路线

机器学习实验先用 sklearn 和经典小数据集，目标是验证概念，不是追求工程完整。

本板块以 Iris 鸢尾花作为主例子。它足够小，又能覆盖数据分析、模型评估、监督学习、无监督学习、特征工程和通往深度学习的桥接实验。

知识正文和实验章节的关系：

- 正文解释知识点在机器学习体系中解决什么问题;
- 正文用 Iris 做一个直观例子，帮助理解指标、模型边界或降维结果;
- 实验 Notebook 负责把同一个例子跑通，生成图和指标;
- 正文通过链接跳到对应实验，实验再反向标注覆盖哪些知识点。

## 第一批实验

| 顺序 | 实验 | 目标 |
|---|---|---|
| 1 | Iris 数据分析与特征理解 | 查看类别分布、单变量分布、特征相关性和散点关系 |
| 2 | 模型评估 | 用 Iris 跑训练/测试划分、交叉验证、混淆矩阵和分类指标 |
| 3 | 监督学习模型对比 | 比较逻辑回归、KNN、决策树、随机森林、SVM、朴素贝叶斯 |
| 4 | 无监督学习模型对比 | 用 PCA、K-means、GMM、层次聚类观察 Iris 结构 |
| 5 | Pipeline 与调参 | 串联标准化、模型、GridSearchCV 和泄漏防范 |
| 6 | MLPClassifier 桥接实验 | 用 sklearn 风格连接多层非线性模型与深度学习 |
| 7 | 线性回归补充实验 | 用极简回归数据理解 MSE、残差和 $R^2$ |

## 数据来源

优先使用：

- sklearn 内置数据集，第一主例子为 Iris;
- UCI / OpenML 小型公开数据;
- Datawhale toy code 中的示例数据。

补充数据只在 Iris 不适合表达时使用：

- 自造一维线性数据：线性回归、残差、过拟合曲线;
- `make_moons` / `make_circles`：非线性决策边界;
- `digits`：通往神经网络和深度学习的桥接。

## Notebook 规划

| Notebook | 覆盖章节 | 主要输出 |
|---|---|---|
| [01_iris_data_analysis](node:irisdata) | 数据与特征 | 分布图、相关性热力图、成对散点图 |
| `02_model_evaluation.ipynb` | 模型评估 | 划分对比、交叉验证、混淆矩阵、分类报告 |
| `03_supervised_models.ipynb` | 监督学习 | 决策边界、树结构、模型指标对比 |
| `04_unsupervised_models.ipynb` | 无监督学习 | PCA 投影、聚类结果、轮廓系数 |
| `05_pipeline_gridsearch.ipynb` | 特征工程与实践范式 | Pipeline、GridSearchCV、泄漏对比 |
| `06_mlp_bridge.ipynb` | 通往深度学习 | MLPClassifier 训练曲线与分类效果 |

每个 Notebook 生成的图保存到 `实验/outputs/`，再由知识正文引用。
