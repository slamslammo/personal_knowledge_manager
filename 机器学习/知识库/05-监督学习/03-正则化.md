# 正则化

正则化通过限制模型复杂度来改善泛化。

## 常见形式

- Ridge / L2:惩罚参数平方和;
- Lasso / L1:惩罚参数绝对值,可产生稀疏参数;
- Elastic Net:L1 与 L2 的组合。

## 理解检查

- 正则化是在损失函数里加了什么?
- 为什么 L1 容易产生稀疏解?
- 正则化强度如何通过验证集选择?
- 特征尺度是否影响正则化效果?

## sklearn 对应

- `Ridge`;
- `Lasso`;
- `ElasticNet`;
- `LogisticRegression(C=...)`。
