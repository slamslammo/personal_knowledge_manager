# 机器学习知识梳理

> 本板块用于系统学习机器学习。中文体系与英文体系都可作为主线；教材负责知识结构与理论，代码资料和 scikit-learn 文档负责可运行实践。

## 机器学习路线图

数据 → 特征 → 模型 → 损失函数 → 优化训练 → 验证评估 → 泛化应用

机器学习不是算法名列表,而是一套从数据到泛化模型的学习闭环。知识组织按三层展开:

| 层级 | 核心问题 | 代表内容 |
|---|---|---|
| 学习框架 | 机器学习在学什么 | 模型、损失、优化、泛化 |
| 数据基础 | 样本和特征如何进入模型 | 数据定义、诊断、预处理、特征工程 |
| 评估方法 | 如何判断模型能否泛化 | 数据划分、指标、过拟合、交叉验证、泄漏 |
| 模型家族 | 不同模型如何表达假设 | 线性模型、树模型、贝叶斯、SVM、集成、聚类、降维 |
| 实践闭环 | 如何可靠训练和复现 | Pipeline、GridSearchCV、Notebook 与实验报告 |
