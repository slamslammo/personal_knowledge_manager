# 机器学习

这是 `personal_knowledge_manager` 的第二个知识管理板块。目标是围绕中英文主线资料系统学习机器学习：从任务与数据定义出发，依次进入特征、模型、损失、优化、评估与泛化，再展开监督学习、无监督学习和 scikit-learn 实践，并与深度学习板块建立明确连接。

## 阅读入口

下载仓库后,直接用浏览器打开:

[知识地图.html](知识地图.html)

该 HTML 使用本目录内的相对路径引用图片和内容,不依赖作者本机绝对路径。内部知识链接使用 `#node=...` 静态路由,可用浏览器前进 / 后退在引用来源与目标节点之间切换。

> 提示:公式渲染依赖联网加载 MathJax CDN。离线打开时正文与图片正常显示,数学公式会暂时呈现为 LaTeX 源码,联网后刷新即正常渲染。

## 板块定位

机器学习板块位于数学基础与深度学习之间:

```text
数学基础 → 机器学习 → 深度学习 → 大模型
```

本板块不是单纯收集算法名,而是按知识体系组织为:

- 数据、特征、标签与任务;
- 模型、损失函数、优化与泛化;
- 模型评估、交叉验证与数据泄漏;
- 经典监督学习与无监督学习模型;
- sklearn 的标准实践范式;
- 通往神经网络与深度学习的桥接。

## 主要资料

中文与英文资料都可以承担完整主线，按语言成本和讲解风格选择入口：

- 周志华《机器学习》:主线教材,用于建立全景。
- 南瓜书:西瓜书公式推导补充,遇到跳步时查。
- Datawhale 西瓜书代码实战:对照公式与代码。
- 李航《统计学习方法》:重点模型加厚。
- scikit-learn 官方文档：实践标准。

- ISLP Python Edition;
- Stanford CS229 Notes;
- Hands-On Machine Learning;
- scikit-learn User Guide。

## 维护方式

修改 `知识库/` 后,在本目录运行:

```bash
python3 build.py
```

然后重新打开或刷新 `知识地图.html`。

图片默认不直接放在 `assets/` 根目录,应按知识节点或内容主题建立子目录。电子书 PDF 不放入公开仓库;如需本地引用,放入本机私有资料目录或被 `.gitignore` 忽略的目录。
