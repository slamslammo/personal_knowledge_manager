# 注意力 → Transformer 加厚 · 配图复现

配套知识点（本板块「注意力 → Transformer」的三个子节点）：

- [输入表示：词元、嵌入与位置编码](../../知识库/04-深度学习/05a-输入表示.md)
- [掩码自注意力](../../知识库/04-深度学习/05b-掩码自注意力.md)
- [语言建模：下一个 token 预测与交叉熵](../../知识库/04-深度学习/05c-语言建模.md)

用最小代码把几个抽象概念画清楚。其中**两张为真实数值计算、可逐像素复现**，两张为**解释性示意图**（已在标题标注「示意」，数值仅为演示）。

## 文件

| 文件 | 说明 |
|---|---|
| `gen_figures.py` | 完整可运行代码，用 `# %%` 分单元；一次生成全部 4 张图到 `figures/` |
| `figures/` | 运行后生成的 4 张图（首次运行自动创建） |

## 运行

```bash
pip install numpy matplotlib
python gen_figures.py        # 生成全部图到 ./figures/
```

> 中文标签需系统装有 CJK 字体（macOS 自带 PingFang/Heiti；Linux 可装 `fonts-noto-cjk`）。缺字体不影响计算，只是中文显示为方块。

## 四张图

| 图 | 类型 | 内容 | 配套节点 |
|---|---|---|---|
| `pos-encoding.png` | 真实计算 | 正弦位置编码矩阵热图 + 不同维度随位置的频率曲线（低维高频、高维低频） | 05a |
| `embed-pipeline.png` | 示意 | 文本 → 词元 → id → 嵌入 → 加位置编码 → 输入向量 | 05a |
| `causal-mask.png` | 真实计算 | 原始注意力分数 → 加因果掩码（未来置 −∞）→ softmax 权重（下三角、每行和为 1） | 05b |
| `lm-next-token.png` | 示意 + 真实 softmax | 自回归「下一个 token 预测」展开 + 某一步的 softmax 分布与交叉熵 | 05c |

> 位置编码与因果掩码两图由公式直接算出，改 `gen_figures.py` 里的序列/维度即可复现与改造；两张示意图的数值仅为演示，用于讲清结构。生成的图同时镜像到 `深度学习/assets/`，供知识节点用相对路径引用。
