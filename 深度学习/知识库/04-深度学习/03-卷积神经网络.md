# 卷积神经网络 CNN

> 处理图像若用全连接 [MLP](node:mlp),参数会随图像尺寸快速膨胀,且没有把"相邻像素更相关、同一局部特征可出现在不同位置"这些**空间结构先验**写进模型。CNN 用**卷积**替代全连接:局部连接 + 参数共享,大幅减少参数,并增强对小位移的鲁棒性——是计算机视觉的基石。记号锚定 d2l 第 6 章。

📌 **过渡承接**:如果从 MLP 到 CNN 的动机还没接上,先读子篇 [从 MLP 到 CNN](node:mlp2cnn)。

📌 **展开阅读**:本节点先给出 CNN 的最小概念框架;完整原理见 [CNN 原理](node:cnnprinciples),经典模型脉络见 [CNN 经典模型](node:cnnmodels)。

## 1. 为什么不用全连接处理图像

一张 $1000\times1000$ 的图展平就是百万维输入,接一个千单元的全连接层就有十亿参数——既算不动也极易过拟合。展平本身并不会删除像素信息,但全连接层没有显式利用"相邻像素相关、同一特征可出现在不同位置"这些先验;模型必须从数据中把这些规律硬学出来。

## 2. 卷积运算:局部加权和 + 参数共享

📌 **前置承接**:[多层感知机](node:mlp) 的全连接层没有利用图像空间结构;CNN 用局部连接与参数共享把这种结构先验写进模型。

用一个小的**卷积核(filter)**在输入上滑动,每到一处就和覆盖的局部区域做**逐元素相乘再求和**,得到输出**特征图**的一个值(深度学习里实际用的是"互相关")。

![卷积核在输入上滑动,每处做局部加权和,生成特征图](../../assets/cnn-overview/cnn-conv.gif)

两个关键性质:**局部连接**(每个输出只看一小块,不是全部像素)与**参数共享**(同一个核扫遍全图)。注意,一层卷积的输出格子数不一定大幅减少;它真正先减少的是可训练参数,并把"同一特征可在不同位置复用"写进结构。同一特征(如边缘)出现在哪里,都能被同一个核检测到;后续再通过 stride、池化或更深层逐步降低空间分辨率、扩大感受野。

## 3. 关键概念:核 / 步幅 / 填充 / 通道

- **卷积核大小**:如 $3\times3$,决定感受野;
- **步幅(stride)**:核每次滑动的格数,步幅大则输出更小;
- **填充(padding)**:在边缘补零,控制输出尺寸、保住边界信息;
- **通道(channel)**:彩色图有 RGB 三通道,每个卷积核跨所有输入通道;一层用多个核 → 多张特征图(多个输出通道),分别检测不同特征。

## 4. 池化:下采样

在每个小区域取最大(**最大池化**)或平均,降低特征图分辨率:减少计算、扩大后续层的感受野,并增强对微小平移的鲁棒性。

![最大池化:每 2×2 取最大值,下采样](../../assets/cnn-overview/cnn-pool.png)

## 5. 典型结构

一个经典 CNN = 若干 **[卷积 + 激活 + 池化]** 块堆叠(逐层提取由低到高的特征:边缘 → 纹理 → 部件 → 物体)→ 末端接全连接层做分类。代表网络:**LeNet**(手写数字)、**AlexNet**(点燃深度学习热潮)、**VGG / ResNet**(更深,ResNet 用残差连接训练上百层)。

![一个完整 CNN:卷积/池化提取空间特征,展平后接全连接层分类](../../assets/cnn-principles/cnn-lee-page30.png)

进一步学习时,先用 [CNN 原理](node:cnnprinciples) 理清局部感受野、参数共享、filter、feature map、pooling;再用 [CNN 经典模型](node:cnnmodels) 把 LeNet、AlexNet、VGG、NiN、GoogLeNet、ResNet、DenseNet 串成结构演进脉络。

## 应掌握的要点
- 全连接处理图像:参数爆炸 + 不利用空间结构;
- 卷积 = 局部加权和 + **参数共享**,带来平移不变、参数大减;
- 核 / 步幅 / 填充 / 通道的作用;多核 → 多特征图;
- 池化 = 下采样,减计算、增平移鲁棒;
- 经典结构 = [卷积+激活+池化] 堆叠 + 全连接;逐层特征由低到高;
- 详细原理见 [CNN 原理](node:cnnprinciples),经典模型结构见 [CNN 经典模型](node:cnnmodels)。
