# 🧠 深度学习

> 背景:深度学习是机器学习的一个**子集**,特指用**多层神经网络**(多层非线性变换的堆叠)来学习数据的表示。它与 [机器学习基础](node:ml) 共享同一套框架(损失 / 优化 / 泛化),此处因内容体量与重要性单独成块。

从 [多层感知机](node:mlp) 起,模型获得隐藏层与非线性,表达力发生质变;[训练:线性模型 → 深度网络](node:training) 说明训练闭环为何不变、梯度来源为何变复杂;[反向传播](node:backprop) 提供了高效计算多层网络梯度的算法。随后进入面向不同数据结构的代表架构:先通过 [从 MLP 到 CNN](node:mlp2cnn) 理解图像为什么需要局部连接与参数共享,再学习 [CNN](node:cnn)(图像)、[RNN](node:rnn)(序列)、[注意力 / Transformer](node:attn)(现代主流)。实验主线的终点,是从零实现一个 mini-GPT。
