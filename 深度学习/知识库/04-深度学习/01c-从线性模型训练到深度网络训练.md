# 从线性模型训练到深度网络训练

> 本篇承接 [线性回归](node:linreg)、[逻辑回归 / softmax 回归](node:softmax) 和 [MLP 引入非线性的作用](node:nonlinear),专门理清一个容易混淆的问题:**训练闭环始终是"前向计算 → 损失 → 梯度 → 参数更新",真正变复杂的是"梯度怎么高效算出来"。** 线性模型的梯度可以直接写公式;深度网络的早期层参数要穿过多层复合函数影响损失,因此需要 [反向传播](node:backprop) 系统化地计算梯度。

## 1. 统一训练闭环

无论线性回归、softmax 回归还是 MLP,训练都在做同一件事:

1. **前向计算**:用当前参数 $\theta$ 算预测 $\hat y=f_\theta(x)$;
2. **计算损失**:用 $L(\hat y,y)$ 衡量预测和真实标签的差距;
3. **求梯度**:计算损失对参数的梯度 $\nabla_\theta L$;
4. **更新参数**:沿负梯度方向走一小步,如 $\theta\leftarrow\theta-\eta\nabla_\theta L$;
5. **重复迭代**:在小批量数据上反复执行,让训练损失下降,再用验证集观察泛化。

这套流程来自 [机器学习概述](node:mlwhat),在线性回归处第一次完整落地。后续模型越复杂,不是训练目标变了,而是模型函数 $f_\theta$ 变复杂,导致第 3 步"求梯度"越来越难。

| 环节 | 线性回归 | 逻辑回归 / softmax | MLP |
|---|---|---|---|
| 模型 | 线性打分 $\mathbf w^\top\mathbf x+b$ | 线性打分 + sigmoid / softmax | 多层线性变换 + 非线性激活 |
| 损失 | MSE | 交叉熵 | 回归用 MSE,分类用交叉熵 |
| 更新 | 梯度下降 / SGD | 梯度下降 / SGD | 梯度下降 / Adam 等 |
| 难点 | 梯度公式直接 | 梯度仍较直接 | 多层复合函数的梯度要高效回传 |

## 2. 线性回归:梯度可以直接写出来

线性回归的模型和损失是:
$$\hat{\mathbf y}=\mathbf X\mathbf w+b,\qquad L=\frac{1}{2n}\|\hat{\mathbf y}-\mathbf y\|^2.$$

令残差 $\mathbf r=\hat{\mathbf y}-\mathbf y$,梯度可直接写成:
$$\frac{\partial L}{\partial \mathbf w}=\frac{1}{n}\mathbf X^\top\mathbf r,\qquad
\frac{\partial L}{\partial b}=\frac{1}{n}\sum_i r_i.$$

于是一次更新就是:
$$\mathbf w\leftarrow\mathbf w-\eta\frac{\partial L}{\partial \mathbf w},\qquad
b\leftarrow b-\eta\frac{\partial L}{\partial b}.$$

这里当然也可以把计算过程画成计算图,甚至让框架用自动微分求梯度。但从理解上看,线性回归的计算图太浅:预测只是一层加权求和,损失是平方误差,梯度一步就能推出来。更特殊的是,平方损失线性回归还有解析解。因此教学上通常不需要专门引入"反向传播算法",直接讲梯度下降就足够。

注意这个表述的边界:不是说线性回归"数学上完全不用链式法则",而是它的链条太短,不需要把链式法则组织成一套专门的反向遍历算法。

## 3. 分类线性模型:损失换了,训练闭环不变

逻辑回归 / softmax 回归把输出从连续值改成类别概率。以多分类为例:
$$\mathbf z=W\mathbf x+\mathbf b,\qquad \mathbf q=\operatorname{softmax}(\mathbf z),\qquad L=-\log q_y.$$

这里模型和损失换了,但训练仍是同一闭环:前向得到概率 $\mathbf q$,用交叉熵算损失,求梯度,再更新 $W,\mathbf b$。交叉熵配 softmax 后,对 logits 的梯度形式很干净:
$$\frac{\partial L}{\partial \mathbf z}=\mathbf q-\mathbf y_{\text{one-hot}}.$$

再由线性打分 $\mathbf z=W\mathbf x+\mathbf b$ 得到 $W,\mathbf b$ 的梯度。它比线性回归多了 sigmoid / softmax 与交叉熵,但整体仍是**浅层模型**:参数只经过一层线性打分就影响损失,没有多层隐藏表示的长链条。因此它通常也不需要把"反向传播"作为独立主题来讲。

## 4. MLP:训练闭环相同,梯度来源变复杂

MLP 的训练并不是另一套规则。以一个隐藏层为例:
$$\mathbf h=\sigma(W_1\mathbf x+\mathbf b_1),\qquad \mathbf o=W_2\mathbf h+\mathbf b_2,\qquad L=L(\mathbf o,y).$$

训练闭环仍然是:

1. 用当前 $W_1,\mathbf b_1,W_2,\mathbf b_2$ 做前向传播,算出 $\mathbf h,\mathbf o$;
2. 用输出 $\mathbf o$ 和标签 $y$ 算损失;
3. 求损失对所有参数的梯度;
4. 用优化器更新所有参数。

真正的新问题在第 3 步。输出层参数 $W_2$ 离损失很近,梯度还相对直接;但第一层参数 $W_1$ 并不直接影响损失,它先影响隐藏表示 $\mathbf h$,再影响输出 $\mathbf o$,最后才影响 $L$:
$$W_1 \rightarrow \mathbf z_1 \rightarrow \mathbf h \rightarrow \mathbf o \rightarrow L.$$

因此 $W_1$ 的梯度必须沿整条链回传:
$$\frac{\partial L}{\partial W_1}
=\frac{\partial L}{\partial \mathbf o}
\cdot\frac{\partial \mathbf o}{\partial \mathbf h}
\cdot\frac{\partial \mathbf h}{\partial \mathbf z_1}
\cdot\frac{\partial \mathbf z_1}{\partial W_1}.$$

网络越深,这样的链越长;每层还可能有矩阵、激活、归一化、残差连接等分支。手工为每个参数单独推公式会迅速失控,直接用数值差分逐个试参数也会极慢且不精确。

## 5. 反向传播解决的是"求梯度",不是"更新参数"

这里要把两个角色分清:

| 问题 | 负责机制 | 它回答什么 |
|---|---|---|
| 梯度怎么得到 | 反向传播 / 自动微分 | 每个参数往哪个方向改,能让损失下降 |
| 参数怎么更新 | SGD / Adam 等优化器 | 拿到梯度后,这一步改多大、怎么改 |

反向传播的作用是:**在前向传播缓存中间结果后,从损失端反向遍历计算图,复用已经算出的下游梯度,一次反向扫描得到所有参数梯度。** 它没有改变"最小化损失"这个训练目标,也没有替代梯度下降;它只是让多层网络的梯度计算变得可行。

所以更准确地说:

- 线性回归:训练 = 前向算预测 + MSE + 直接梯度公式 + SGD;
- softmax 回归:训练 = 前向算概率 + 交叉熵 + 直接梯度公式 + SGD;
- MLP:训练 = 前向传播 + 损失 + **反向传播求梯度** + SGD / Adam。

三者的训练闭环一致,差异在于模型复杂度与梯度计算方式。

## 6. MLP 的完整训练过程放在哪里讲

在原理主线里,MLP 训练讲到这里即可:读者需要掌握"训练闭环不变、求梯度变复杂、反向传播因此登场"。更工程化的细节,例如 epoch、batch、训练集 / 验证集、优化器选择、学习率曲线、过拟合曲线,更适合放到后续实验主线中讲。

后续实验会用代码把这个循环展开成可运行版本:初始化参数;按 epoch 反复遍历数据;每次取一个 batch 做前向传播、计算损失、反向传播求所有参数梯度、执行优化器 step 更新参数、清空梯度;每轮结束后在验证集上观察泛化。

因此 MLP 正文只需要说明训练闭环与动机;本篇负责把线性模型到深度网络的训练差异讲清;下一篇 [反向传播与计算图](node:backprop) 再专门展开"梯度如何一层层回传"。

## 常见误解

- **误解 1:深度学习训练 = 反向传播。** 不准确。反向传播只负责求梯度;训练还包括前向传播、损失、优化器更新和泛化评估。
- **误解 2:线性回归不能用反向传播。** 不准确。线性回归也能被框架放进计算图自动求导,只是它太浅,手写梯度更直接。
- **误解 3:MLP 的更新规则和线性回归完全不同。** 不准确。更新仍是沿梯度降低损失,只是梯度由反向传播高效算出。

## 应掌握的要点

- 所有监督学习模型共享"前向计算 → 损失 → 梯度 → 更新"的训练闭环;
- 线性回归和 softmax 回归是浅层模型,梯度可以直接写出,不必单独引入反向传播;
- MLP 的参数通过多层复合函数间接影响损失,早期层梯度需要沿计算图回传;
- 反向传播负责**求梯度**,SGD / Adam 负责**用梯度更新参数**;
- MLP 的代码级训练流程留给实验主线,原理主线先讲清"为什么需要反向传播"。
