## ② 新发布与技术 Top 5

### DeepSeek 开源推理框架 DeepInfer

- **是什么**：10 月 20 日以 Apache 2.0 许可开源，DeepSeek 称这是其线上 DeepSeek-V4.1-Flash 服务所用的推理框架。同时支持 NVIDIA SM100 GPU 和华为昇腾 950，内含此前开源的 FlashMLA、DeepGEMM、DeepEP，同期还开源了负责 token 编解码的 deepseek-recipe。
- **新在哪里**：此前开源的是单个算子和通信库，这次是整套生产推理框架，并原生支持国产芯片。发布范围限于离线推理，不含 KV cache 系统、预填充与解码分离和副本负载均衡；性能数据是 DeepSeek 在 NVIDIA 硬件上自测的。
- **对谁有影响**：自部署 DeepSeek 模型的团队、推理框架开发者，以及昇腾生态。
- **原文**：[deepseek-ai/DeepInfer](https://github.com/deepseek-ai/DeepInfer)；HN 2353 分，为本周最高分；报道见 [TechNode](https://technode.com/2026/10/21/deepseek-open-sources-inference-framework-with-support-for-nvidia-and-huawei-chips/)

### Moonshot 发布 Kimi K3.1 Pro 与 K3.1 Pro Highspeed

- **是什么**：10 月 23 日发布的旗舰模型及其高速版，即日起在 Kimi.com、Kimi Work、Kimi Code 和 Kimi API 上可用。
- **新在哪里**：Highspeed 是同一模型的高速服务档位，官方称速度是标准版的 2–3 倍、能力相同，但额度消耗更高。据报道，官方发布文称将在 11 月 4 日前开放权重。Artificial Analysis 给出的综合评分为 55，位于性价比的帕累托前沿上。
- **对谁有影响**：长上下文编程和智能体场景的开发者；开放权重后，自部署用户也会受益。
- **原文**：[Kimi K3.1 Pro 发布文](https://www.kimi.ai/blog/kimi-k3-1-pro)；HN 1096 分；评测见 [Artificial Analysis](https://artificialanalysis.ai/models/kimi-k3-1-pro)

### Anthropic 推出主动式智能体应用 Claude Duet（研究预览）

- **是什么**：10 月 21 日发布的独立应用，会主动检查用户连接的账户和工具，替用户推进工作，付款、删除等不可逆操作前先确认。目前仅向美国的 Pro、Max 用户开放候补名单。
- **新在哪里**：从"用户提问、模型回答"转向"智能体先找你"。Anthropic 也说明了局限：判断紧急程度还在调优，账户每隔几小时检查一次而不是实时，订机票之类的个人事务还处理得不好。
- **对谁有影响**：专业人士和小企业主；媒体普遍把它视为对 OpenAI Dots、Meta Muse 的回应（仅媒体报道）。
- **原文**：[Claude Duet 产品页](https://claude.com/product/claude-duet)；HN 567 分

### OpenAI 模型与 Codex 进入 Google Cloud

- **是什么**：10 月 21 日宣布，OpenAI 的前沿模型和 Codex 智能体工作流将通过 Google Cloud 的 Model Garden 提供，企业可以经 Marketplace 购买，并抵扣已有的 Google Cloud 承诺消费。
- **新在哪里**：OpenAI 前沿模型此前主要通过 Azure 提供；据报道，微软与 OpenAI 在 4 月调整合作后，OpenAI 可以在其他云上销售。具体上线哪些型号，只见于部分媒体报道（仅媒体报道）。
- **对谁有影响**：以 Google Cloud 为主的企业，尤其是要在现有访问控制和数据治理体系下使用 OpenAI 模型的受监管行业。
- **原文**：[OpenAI models are coming to Google Cloud](https://openai.com/index/openai-models-google-cloud/)；HN 326 分

### Anthropic：大模型让大规模形式化验证变得可行

- **是什么**：Anthropic 前沿红队与验证公司 Theorem 合作，10 月 22 日发布研究：Claude 在 RISC-V 汇编层面，为 123 个开源库的 239 个模糊测试入口写出了机器可检验的正确性证明，还发现了一个潜伏十多年的逻辑错误。
- **新在哪里**：形式化验证过去要专家投入数年；Anthropic 称，据其所知，这是首次在汇编层面对生产软件大规模应用 AI 形式化验证。局限是证明只保证代码满足写下来的规格，规格有遗漏，保证就有遗漏。
- **对谁有影响**：安全关键软件的维护者和软件供应链安全从业者。
- **原文**：[LLMs are making formal software verification feasible](https://www.anthropic.com/research/formal-verification)；HN 464 分

### 1. [morluto/rea](https://github.com/morluto/rea)

总 star 399,491（本周 +62,679）｜给编码智能体用的逆向工程 CLI 和 MCP 服务器，能从应用行为一路分析到原生二进制。

- **本周为什么火**：没有新的单一触发事件，是持续的爆发：它在 W41、W42 都是增量第一（分别 +100,940、+218,979），本周仍居首位。上周 NSA 的逆向工具 Ghidra 也出现在周榜上，YouTube 上有视频把两者联系在一起。
- **传播分析**：传播主要靠 YouTube 教程，标题多为"用 REA 几分钟克隆任何软件""把 NSA 的 Ghidra 交给你的 AI 智能体"，内容集中在配合 Claude Code、Codex、Cursor 安装和使用（[教程示例](https://www.youtube.com/watch?v=HvfmnI6wl5c)、[实测视频](https://www.youtube.com/watch?v=yBrJzwKtjX8)）。网页上主要是聚合站的趋势报道（[示例](https://aiweekly.co/alerts/github-morlutorea-reverse-engineer-anything-with-agents-from-app-behavior-down)），没有找到深度技术评测。
- **我们的判断**：适合安全研究、互操作开发和遗留系统分析。它把 Ghidra、IDA 等专业工具接到智能体上，门槛大幅降低，但"克隆任何软件"式的宣传有法律风险，使用时要注意许可协议和逆向条款。项目创建才半年，star 增长极快，社区成熟度还有待观察。

### 3. [Ebony-Vinyl/dsh-our-free-model](https://github.com/Ebony-Vinyl/dsh-our-free-model)

总 star 47,840（本周 +18,181）｜DeepSeek Harness（dsh）的第三方插件，不用登录、注册或 API key，就能在 dsh 里使用 DeepSeek V4.1 Flash、Kimi K3 等模型。

- **本周为什么火**：连续三周上榜（W41 新晋、W42 第 3 名、本周第 3 名）。本周没有找到新的单一触发事件，从项目描述和传播内容看，吸引力主要在"免费、免 key"。
- **传播分析**：AlphaSignal 的报道说，插件把公开、免 key 的模型接入 dsh 的模型选择器，并经 OpenCode Zen、Kilo AI 等公共网关转发请求（[报道](https://alphasignal.ai/news/deepseek-harness-plugin-unlocks-free-models-without-an-api-key)）。YouTube 上有英文、日文讲解视频（[示例](https://www.youtube.com/watch?v=4RH7ItgYUBM)、[日文解说](https://www.youtube.com/watch?v=T1g4kOrrvOY)）。
- **我们的判断**：适合个人尝鲜，不适合工作或敏感代码。"免费"依赖第三方网关的公开额度，服务条款、稳定性和数据去向都不透明；请求会经过网关，代码和对话内容存在泄露风险。

### 4. [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill)

总 star 50,760（本周 +15,667）｜Cloudflare 开源的编码智能体安全审计技能（MIT 许可），由指令、攻击检查清单和小型校验器组成，分六个阶段审计代码库。

- **本周为什么火**：搜索没有找到本周的明确触发事件；同周 PHP2Shell 等"AI 找漏洞"事件密集（见 ⑤），安全审计类工具整体受关注。
- **传播分析**：评测文章强调它的核心规则是"发现漏洞的智能体不负责复核"，每条发现都交给另一个智能体独立验证（[分析](https://redreamality.com/blog/cloudflare-security-audit-skill-for-coding-agents/)）。YouTube 上以"把 Claude Code 变成渗透测试员"为题的安装教程较多（[示例](https://www.youtube.com/watch?v=WMnbA2hDtKI)、[六阶段解析](https://www.youtube.com/watch?v=MqSqRgo1Es0)）。
- **我们的判断**：适合想在提交前做一轮安全审查的团队，可以直接用在 Claude Code、Codex 等工具里。它不是扫描器，结果依赖模型能力；据报道 README 称单次运行只能发现多次运行总数的一半左右，而且会启动大量子智能体，时间和 token 成本较高。

### 5. [google-research/harness2](https://github.com/google-research/harness2)

总 star 20,737（本周 +13,484）｜Harness²：让智能体在不改模型权重的前提下，递归改进自己的运行框架（提示词、工具、记忆、规则）。

- **本周为什么火**：论文（arXiv 2610.14224）和代码本周受到关注，HN 81 分；"harness 工程"本周在 HN 上热度很高，相关帖子还有 [Harness Engineering 101](https://news.ycombinator.com/item?id=50151390)，以及用 GVS5H harness 让小模型追平前沿模型的[实验](https://news.ycombinator.com/item?id=50228167)。
- **传播分析**：解读集中在"不训练也能自我改进"。论文报告在 WorkBuddy-Bench、JobBench、LAB 上最多提升 11.8 个百分点（[解读](https://themenonlab.blog/blog/harness2-recursive-agent-harnessing-google)）。YouTube 上有原理讲解和实测视频，也有人提出"这是不是 harness 工程的终结"（[示例](https://www.youtube.com/watch?v=yCgfyQmqhPM)）。
- **我们的判断**：适合研究智能体框架、需要在开放任务上调优智能体的团队。目前是研究代码，提升数据来自论文作者，能否迁移到生产任务还需要验证。

## 洞察

### 洞察 1：AI 让软件安全进入"攻防同速"

- **依据**：② Anthropic 用 Claude 为 123 个开源库做汇编级形式化验证；③ cloudflare/security-audit-skill 进入前五；⑤ PHP2Shell 由 AI 辅助发现，同周 LiteLLM 遭投毒。防守方在用 AI 找漏洞、写证明，AI 工具链本身也成了攻击目标。
- **必读**：[Anthropic：LLMs are making formal software verification feasible](https://www.anthropic.com/research/formal-verification)：看清 AI 验证代码现在能做到什么规模，以及"规格写不全"这个根本限制；[Wiz：PHP2Shell](https://www.wiz.io/blog/php2shell-php-rce)：一次 AI 辅助发现关键漏洞的完整过程。

### 洞察 2：智能体的竞争重心从模型转向运行框架

- **依据**：③ 前五里有四个是智能体周边的工具或框架（rea、dsh-our-free-model、security-audit-skill、Harness²）；Harness² 让智能体不改权重、递归改进自己的运行框架，HN 上用 GVS5H 框架让小模型追平前沿模型的实验也受关注；② Claude Duet 和 OpenAI Codex 进入 Google Cloud，比拼的也是产品形态和分发渠道。
- **必读**：[google-research/harness2](https://github.com/google-research/harness2)：代码与论文入口，了解"改框架、不改模型"的具体做法；[Harness Engineering 101](https://github.com/IsuruMaduranga/harness-engineering-101)：入门材料，把模型比作大脑、把框架比作身体。

### 洞察 3：中国厂商从开源模型走向开源整套技术栈，同时遭遇政策阻力

- **依据**：② DeepSeek 开源生产推理框架 DeepInfer 并支持昇腾，Moonshot 预告 11 月 4 日前开放 Kimi K3.1 Pro 权重；③ DeepInfer 排第 2，基于 DeepSeek Harness 的插件排第 3，DeepSeek Harness 本身也在候选名单里（本周 +8,294）；⑤ 同一周，美国国土安全部把 DeepSeek 及基于它的第三方产品排除出联邦民用采购。
