# AI 周报 · 2026-W43（10/19–10/25）

## ① 本周概览

- **中国厂商**：DeepSeek 开源了线上服务用的推理框架 DeepInfer，拿下本周 HN 最高分；Moonshot 发布 Kimi K3.1 Pro，承诺 11 月 4 日前开放权重。
- **语音与智能体**：Mistral 发布 Voxtral 3 语音模型家族和语音智能体 SDK；Anthropic 推出会主动找用户的智能体应用 Claude Duet。
- **安全**：AI 辅助发现的 PHP2Shell 漏洞随补丁公开，Claude 为 123 个开源库写出形式化证明，同一周 LiteLLM 的发布管线被攻破。

## 洞察

### 洞察 1：AI 同时加快了找漏洞和修漏洞，AI 工具链自己也成了攻击目标

- **依据**：② Anthropic 用 Claude 在汇编层为 239 个模糊测试入口写出可机器检验的证明，修掉了潜伏多年的 bug；③ cloudflare/security-audit-skill 本周 +15,667 star；⑤ PHP2Shell 中至少一个漏洞由 AI 系统发现，而 Amazon 在补丁公开前 4 天就观测到利用；同周 LiteLLM 被投毒，恶意版本专偷云和 AI 服务凭证。发现、修复、利用三端都在提速，集中保管模型密钥的 AI 网关成了高价值目标。
- **必读**：[Anthropic：LLMs are making formal software verification feasible](https://www.anthropic.com/research/formal-verification)：看 AI 形式化验证现在能做到什么规模，以及证明只覆盖特定平台和规格这一限制；[Wiz：PHP2Shell](https://www.wiz.io/blog/php2shell-php-rce)：一次 AI 辅助发现关键漏洞、多方协调披露的完整时间线。

### 洞察 2：智能体之间的差距，越来越多地来自运行框架而不是模型

- **依据**：③ Top 5 里有四个是智能体周边：给智能体用的逆向工具 rea、dsh 的模型插件、Cloudflare 的审计技能、Google 的 Harness²。Harness² 不改权重、只递归改进框架，论文报告最多提升 11.8 个百分点。HN 上"harness 工程"讨论集中，Harness Engineering 101（132 分）和用 GVS5H 框架让 Qwen3.8-27B 追平前沿模型的实验（185 分）都上了首页。② Claude Duet 比拼的也是"主动工作 + 审批"这种产品形态。
- **必读**：[google-research/harness2](https://github.com/google-research/harness2)：代码和论文入口，看"改框架、不改模型"具体改了哪些部分；[Harness Engineering 101](https://github.com/IsuruMaduranga/harness-engineering-101)：入门材料，把模型比作大脑、把框架比作身体。

### 洞察 3：DeepSeek 把开源推进到推理栈，通用引擎几天就跟上，政策阻力同时加大

- **依据**：② DeepInfer 原生支持华为昇腾 950，Kimi K3.1 Pro 承诺开放权重；③ DeepInfer 第 2，基于 DeepSeek Harness 的插件第 3；开源 4 天后，SGLang（LMSYS）发文称在 DeepInfer 自己的基准上持平或略优，vLLM 也宣称追平（均为自报）。⑤ 同一周，美国国土安全部把 DeepSeek 及基于它的第三方产品排除出联邦民用采购。开源推理框架的技术领先很快被吸收，影响中国厂商的变量更多来自政策。
- **必读**：[deepseek-ai/DeepInfer](https://github.com/deepseek-ai/DeepInfer)：看 DeepSeek 线上推理栈开源了哪些部分、还缺哪些部分；[LMSYS：SGLang 与 DeepInfer 对比](https://www.lmsys.org/blog/2026-10-24-dsv41-deepinfer)：通用引擎怎样在几天内吸收专用框架的优化。

## ② 新发布与技术 Top 5

### DeepSeek 开源推理框架 DeepInfer

- **是什么**：10 月 20 日以 Apache 2.0 许可开源的推理框架，报道称它就是 DeepSeek 自家线上服务所用的推理引擎。支持 NVIDIA SM100（Blackwell）GPU 和华为昇腾 950 NPU；首个版本只提供离线推理，只支持 DeepSeek-V4.1-Flash。
- **新在哪里**：DeepSeek 此前开源的是 FlashMLA、DeepGEMM、DeepEP 等算子和通信库，这次是整套推理框架，并把昇腾作为一等目标。README 写明最初基于 vLLM 构建。完整的线上服务还缺 KV cache 系统、预填充与解码分离和副本间负载均衡；不支持 Hopper 等较老的 NVIDIA 架构。
- **对谁有影响**：自部署 DeepSeek 模型的团队、推理框架开发者和昇腾生态。vLLM 和 SGLang 已发文称在 DeepInfer 公布的基准上追平，相关数据都是各方自测。
- **原文**：[deepseek-ai/DeepInfer](https://github.com/deepseek-ai/DeepInfer)；HN 2353 分，为本周最高分；报道见 [TechNode](https://technode.com/2026/10/21/deepseek-open-sources-inference-framework-with-support-for-nvidia-and-huawei-chips/)、[SCMP](https://www.scmp.com/tech/big-tech/article/3371592/deepseek-open-sources-new-tool-slash-ai-costs-fight-against-closed-source-rivals)

### Moonshot 发布 Kimi K3.1 Pro 与 K3.1 Pro Highspeed

- **是什么**：10 月 23 日发布的旗舰多模态推理模型及其高速版，通过 API 提供，上下文 100 万 token。
- **新在哪里**：Highspeed 是同一模型的高速档，输出快约 2–3 倍，额度消耗约翻倍。Moonshot 称 Terminal-Bench 4.0 得分 65.7%，比 Claude Opus 5.5 的 66.4% 低不到 1 个百分点（厂商自报）；Artificial Analysis 综合评分 55，处在性价比帕累托前沿上。Moonshot 承诺 11 月 4 日前开放权重，并称开放前已从训练数据中移除网络攻击相关内容；许可证尚未公布。
- **对谁有影响**：长上下文编程和智能体开发者；权重开放后的自部署用户。据报道，标准版 API 为每百万 token 输入 2 美元、输出 10 美元（来源：Let's Data Science 等）。
- **原文**：[Kimi K3.1 Pro 发布文](https://www.kimi.ai/blog/kimi-k3-1-pro)；HN 1096 分；评测见 [Artificial Analysis](https://artificialanalysis.ai/models/kimi-k3-1-pro)（HN 121 分）

### Mistral 发布 Voxtral 3 语音模型家族与语音智能体 SDK

- **是什么**：10 月 20 日发布。语音转文字有三款（批量转写 Mini Transcribe 3 和 Small Transcribe 3、实时转写 Mini Transcribe Realtime 3），文字转语音有 TTS 3 和 TTS Realtime 3 两款，另附语音智能体 SDK。
- **新在哪里**：转写覆盖 50 多种语言，语音合成覆盖 35 种以上语言。SDK 基于 LiveKit，把语音输入、推理、工具调用和语音输出串成一条流式管线。官方变更日志标为公开预览；有报道称这一代没有像前代那样开放权重。定价：Mini 转写每分钟 0.0035 美元，TTS 每百万字符 13 美元。
- **对谁有影响**：做语音客服和实时语音智能体的开发者；Voxtral 2 用户可按迁移指南切换。性能对比（如优于 Whisper）来自 Mistral 自己的测试。
- **原文**：[Voxtral 3](https://mistral.ai/news/voxtral-3/)；HN 770 分；[从 Voxtral 2 迁移](https://docs.mistral.ai/studio/audio/migrate-from-voxtral-2)

### Anthropic 推出主动式智能体应用 Claude Duet（研究预览）

- **是什么**：10 月 21 日推出的独立应用（iOS、Android 和 claude.ai），美国的 Pro、Max 用户可加入候补名单。它每天早上推送简报，白天检查已连接的应用，只在需要用户决定时提醒，关掉应用后仍在后台工作。
- **新在哪里**：从"用户提问、模型回答"变成"智能体先找你"。发消息、付款、签文件、删除前，会展示具体操作并等待批准；安全说明称它看不到密码、浏览器 cookie 和登录令牌，并用一个独立的分类器检查外发消息是否含敏感信息。后台检查计入用量限额。
- **对谁有影响**：依赖邮件、日程和各类 SaaS 工具的专业人士；媒体普遍把它视为对 Meta Muse、OpenAI dots 的回应（仅媒体报道）。
- **原文**：[Introducing Claude Duet](https://claude.com/resources/articles/claude-duet)、[安全与隐私说明](https://claude.com/resources/articles/claude-duet-safety-privacy-and-security)；HN 567 分

### Anthropic 与 Theorem：用 Claude 为 123 个开源库写形式化证明

- **是什么**：10 月 22 日发布的研究。Claude 把 OSS-Fuzz 中 123 个开源库的 239 个模糊测试入口转成形式化规格，在 RISC-V 汇编层写出可机器检验的 Rocq 证明，证明这些入口在 64 MB 以内的输入下不会崩溃。
- **新在哪里**：证明总量约 1.8 亿行，用时几周。验证中发现的 bug 由 Claude 修补后重新证明，其中一些已潜伏多年。局限也很明确：结论只针对单线程、静态链接 musl 的 RISC-V 二进制和建模的 Linux 环境，大多数人使用的 x86、ARM 加 glibc 构建不直接覆盖；Theorem 的公开仓库目前只有 25 个库的 60 个入口。
- **对谁有影响**：基础库维护者和软件供应链安全团队。
- **原文**：[LLMs are making formal software verification feasible](https://www.anthropic.com/research/formal-verification)；HN 472 分

总 star 50,002（本周 +18,181）｜DeepSeek Harness（dsh）的第三方插件，不用登录、注册或 API key，就能在 dsh 里使用 DeepSeek V4.1 Flash、GLM 5.3 Flash、Kimi K3 等模型。

- **本周为什么火**：连续三周上榜（W41 新晋、W42 第 3、本周第 3）。没有找到本周新的触发事件，吸引力主要在"免费、免 key"；同周 DeepSeek 相关项目整体走高，deepseek-harness 本身本周也 +8,294。
- **传播分析**：AlphaSignal 的报道说，插件把公开、免 key 的模型加进 dsh 的模型选择器，请求转发到 OpenCode Zen 和 Kilo AI 两个公共网关（[报道](https://alphasignal.ai/news/deepseek-harness-plugin-unlocks-free-models-without-an-api-key)）。YouTube 上有英文、日文讲解和源码级教程，后者专门讲了安装安全和本地网关安全（[讲解](https://www.youtube.com/watch?v=4RH7ItgYUBM)、[源码教程](https://www.youtube.com/watch?v=6dYm2fGoeIc)）。

### 4. [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill)

总 star 52,168（本周 +15,667）｜Cloudflare 开源的编码智能体安全审计技能（MIT 许可）。它不是扫描器，而是给智能体一套方法：划定信任边界、调查候选缺陷、独立复核、输出机器可读的结果。

- **本周为什么火**：仓库 6 月创建，9 月中旬起已有大量报道，本周没有找到新的发布或明确触发事件；同周 PHP2Shell 等"AI 找漏洞"事件密集（见 ⑤），可能带动了关注（推测）。
- **传播分析**：YouTube 上以"把 Claude Code 变成渗透测试员"为题的安装教程最多（[示例](https://www.youtube.com/watch?v=WMnbA2hDtKI)）；播客式解读强调它的六个阶段和"发现漏洞的智能体从不复核自己的发现"（[解读](https://www.youtube.com/watch?v=VXCnghv_0v0)）。网页评测关注它的可验证工作流（[分析](https://redreamality.com/blog/cloudflare-security-audit-skill-for-coding-agents/)）。
- **我们的判断**：适合想在提交前做一轮安全审查的团队，可以直接装进 Claude Code 等工具。需要支持工具调用和并行子智能体的模型，token 成本高；结果要人工复核，有视频建议只在系统级沙箱中运行、只审计自己有权测试的代码。

### 5. [google-research/harness2](https://github.com/google-research/harness2)

总 star 21,177（本周 +13,484）｜Google Research 与西北大学的 Harness²：模型权重不动，递归改进智能体的运行框架（提示词、工具、记忆、编排）。

- **本周为什么火**：论文（arXiv 2610.14224）和代码受到关注，HN 81 分；本周 HN 上"harness 工程"话题集中，还有 [Harness Engineering 101](https://news.ycombinator.com/item?id=50151390)（132 分）和用 GVS5H 框架让小模型追平前沿模型的[实验](https://news.ycombinator.com/item?id=50228167)（185 分）。
- **传播分析**：解读集中在"不训练也能自我改进"：任务级用对比式的提出、试探、组合步骤改进当前框架，再把经验沉淀到持续改进的框架里。论文报告在 WorkBuddy-Bench、JobBench、LAB 上分别最多提升 11.5、4.5、11.8 个百分点（[解读](https://themenonlab.blog/blog/harness2-recursive-agent-harnessing-google)）。YouTube 上有讲解和实测，也有人问"这是不是 harness 工程的终结"（[示例](https://www.youtube.com/watch?v=yCgfyQmqhPM)）。
- **我们的判断**：适合研究智能体框架、要在开放任务上调优智能体的团队。仓库注明"不是 Google 官方支持的产品"，核心代码 Apache 2.0；演示不需要模型凭证，跑真实基准要花 API 费用。提升数据来自论文作者，能否迁移到生产任务还要验证。
