# AI 资讯

这是 `personal_knowledge_manager` 的信息流板块：由定时任务每周一自动汇总上一周的 AI 关键内容，按周报、月报、季报长期积累，便于按时间和主题回溯。

与其他知识板块不同，本板块以资讯为主，允许大量外链，每条资讯都附原始链接供深入阅读。周报保留资讯原貌，月报和季报以分析和判断为主。每期报告开头带元数据（主题、机构、项目），可按内容检索。

> 当前状态：开发阶段（v0.1 验收中），定时任务尚未部署。进展见 [任务/版本规划.md](任务/版本规划.md)。

## 内容

| 产出 | 路径 | 频率 |
| --- | --- | --- |
| 周报 | `周报/{ISO 周年}/{WEEK}.md` | 每周一 |
| 月报 | `月报/{年}/{年}-{MM}.md` | 每月最后一周结束后的周一 |
| 季报 | `季报/{年}/{年}-Q{N}.md` | 每季度最后一周结束后的周一 |
| 榜单数据 | `数据/github-weekly/{WEEK}.json` | 每周一 |

周报包含六个板块：本周概览、新发布与技术 Top 5、GitHub AI 项目热度 Top 5、传播文章 Top 5、热点话题 Top 5、洞察。

## 任务工程

生成这些内容的定时任务作为子项目维护在 [任务/](任务/)：

- [方案.md](任务/方案.md)：板块规划、内容规则、数据源、运行架构
- [版本规划.md](任务/版本规划.md)：版本路线与迭代记录
- [部署指南.md](任务/部署指南.md)：部署与迁移步骤
- `config/`：部署清单、信息源、榜单参数、主题词表
- `prompts/`：入口提示词与执行手册
- `templates/`：报告模板
- `scripts/`：采集、排名、校验脚本
