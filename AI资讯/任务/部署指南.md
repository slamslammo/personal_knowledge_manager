# 部署指南

> 本文说明如何把 AI 资讯任务部署到定时运行平台。部署所需的全部参数集中在 `config/task.yaml`，本文按平台说明怎么配置。

## 1. 部署前提

任何平台都需要满足：

| 能力 | 用途 |
| --- | --- |
| 定时触发 | 每周一 10:00（Asia/Shanghai）运行 |
| Shell、python3、curl | 计算日期、请求接口、解析数据 |
| 访问外网 | Trendshift、OSS Insight、HN Algolia、Hugging Face，见 `config/task.yaml` 的 `network.allow` |
| 联网搜索 | 官方发布、媒体报道、传播分析 |
| 推送本仓库 | 提交周报和数据文件到 `main` |
| 发送通知 | 把周报精简版推送给用户 |

模型选择平台上的中档通用模型即可。仓库文件中不写具体型号，在平台设置中选择。

## 2. Claude Code 云端定时任务（当前平台）

### 2.1 环境

1. 打开定时任务使用的云端环境，网络访问设为"完全访问"，或者在白名单中加入 `config/task.yaml` 列出的域名。
2. 注意：环境可能被多个会话和定时任务共用，修改会影响所有使用该环境的任务。如需隔离，可单独建一个环境给本任务。
3. 环境中不需要配置额外的密钥或 token。

### 2.2 GitHub 授权

1. 账户级：在设置的"连接器 → GitHub 集成"中连接 GitHub 账户，并安装 Claude GitHub 应用，确认"查看仓库状态"显示云端会话可以在本仓库中工作。
2. 任务级：在定时任务的编辑页把本仓库加入仓库或来源列表。云端会话只能推送已挂载的仓库，挂载在会话启动时确定，运行中的会话不会补加。

### 2.3 定时任务配置

| 项目 | 设置 |
| --- | --- |
| 运行时间 | 每周一 10:00，时区 GMT+8 |
| 模型 | 中档通用模型 |
| 仓库 | slamslammo/personal_knowledge_manager |
| 提示词 | 复制 `prompts/routine-prompt.md` 全文 |

v0.1 起，正式手册 `prompts/weekly.md` 进入仓库。过渡提示词会在第 0 步检测到它并改为按手册执行，因此定时任务里的提示词不需要再修改。

### 2.4 上线检查

正式启用前手动触发一次，检查：

- [ ] 周报文件生成在 `AI资讯/周报/{ISO 周年}/{WEEK}.md`
- [ ] 数据文件生成在 `AI资讯/数据/github-weekly/{WEEK}.json`
- [ ] 提交成功推送到 `main`；如果被拒，确认是否改推到了 `claude/ai-weekly-archive`
- [ ] 手机收到通知，首句格式为"【AI周报 W..】……"，全文链接可以打开
- [ ] 数据说明中各数据源均采集成功

## 3. 迁移到其他平台

### 3.1 能力对应

| 提示词中的能力 | Claude Code 云端 | 其他平台的对应做法 |
| --- | --- | --- |
| 联网搜索 | 内置搜索工具 | 平台内置搜索，或调用搜索 API |
| 推送通知 | PushNotification（`<routine_summary>` 首句为横幅） | 邮件、飞书或其他 IM 机器人 Webhook、GitHub Issue |
| 推送本仓库 | 挂载仓库后由平台注入凭证 | 部署密钥或细粒度 token，只授予本仓库内容写权限 |

迁移时复制 `prompts/routine-prompt.md`，把"PushNotification"一节替换为目标平台的通知方式，其余步骤不变。

### 3.2 Codex 或本地 cron

1. 准备运行环境：python3、curl、git，能访问外网。
2. 克隆本仓库，配置只对本仓库有写权限的凭证。
3. 按 `config/task.yaml` 的 `schedule` 配置定时，用平台的命令行模式执行提示词。
4. 按 2.4 的清单做一次上线检查。

## 4. 故障排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 推送报 403，提示仓库不在授权列表 | 定时任务没有挂载本仓库 | 在定时任务编辑页挂载仓库 |
| api.github.com 返回 403 | 云端会话只允许访问已挂载仓库的接口 | 不要使用 GitHub 搜索和 Trending，改用 Trendshift |
| curl 报 CONNECT 403 | 环境网络策略拦截 | 检查环境网络设置是否为"完全访问"或已加入白名单 |
| OSS Insight 请求超时 | 接口偶发挂起 | 缩短超时并重试；失败的仓库在数据说明中注明 |
| Trendshift 解析不到 ItemList 或每日数据 | 页面结构变化 | 在数据说明中记录，修订提示词或脚本中的解析规则 |
