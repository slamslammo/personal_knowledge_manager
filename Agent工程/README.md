# Agent 工程

本板块以 Datawhale [Hello-Agents](https://github.com/datawhalechina/hello-agents)《从零开始构建智能体》为核心材料，按知识逻辑重新组织智能体（Agent）的核心知识，并逐步补充机制分析与可复现实验。

## 阅读入口

下载仓库后，用浏览器直接打开 [知识地图.html](知识地图.html)。首页是七个部分的知识图谱，点击部分进入该部分的知识点清单。

该 HTML 只使用本目录内的相对路径；内部链接使用 `#node=...` 静态路由，可以用浏览器前进、后退切换。

## 组织方式

板块结构从核心材料对智能体的知识结构中提炼，按知识逻辑排列，不按教材章节顺序转写：

```text
智能体是什么 → 运行机制 → 行动：工具与协议 → 信息：上下文、记忆与检索
→ 构建：框架与多智能体 → 验证与提升：评估与训练 → 应用形态
```

- 同一概念只维护一份主解释，其他知识点通过 `node:` 内链引用。
- 每个部分是一个一级节点（部分目录下的 `00-*.md`），维护本部分回答的问题、知识点表格、主线与相邻关系。
- **知识点表格是首页图谱的唯一数据源**：`build.py` 读取各部分 `## 知识点` 表格生成图谱，不在其他地方重复维护知识点清单。表格第 1 列是知识点名称，最后 1 列是状态。
- 状态只使用四个值：已发布 / 编写中 / 未展开 / 读者前提，含义与读者前提清单见 `知识库/00-总览.md`。“读者前提”的知识点只保留位置与教材章节，不写正文。

## 发布一个知识点

1. 在对应部分目录下新增 md，顶部写 `<!--# id -->`，id 一经建立不再修改。
2. 在部分节点的知识点表格中，把名称改为 `[名称](node:id)`，状态改为“已发布”。
3. 在 `build.py` 的 TREE 中把该节点登记为对应部分的 `children`。
4. 运行 `python3 build.py`，处理脚本输出的一致性提示。

## 知识点写法

正文按四层组织：

1. **定位**：回答什么问题、在体系中的位置、前置知识；读者前提用一行链接指向教材小节，不重讲。
2. **核心解释**：2–5 分钟可读完，先给统摄性的原理，再给由此推出的关键结论。
3. **机制深挖**：对照教材代码、设计选项与失效情形。
4. **实验与原文**：可复现实验与教材原文位置；未运行的实验不写复现声明。

末尾固定两节：`## 与相邻知识点的关系`（显式内链）与 `## 来源与核验`（表格：结论 | 依据位置 | 级别）。

## 来源、核验与引用

- 来源分级、引用写法与〔待核验〕标注规则只在 `知识库/08-参考资料.md` 维护。
- 教材引用版本固定为主分支提交 `4f7682c`；升级版本时统一复核小节号。
- 教材采用 CC BY-NC-SA 4.0，本仓库为 MIT：正文以转述与分析为主，短句引用注明位置，不转载教材图片与大段代码。
- 补充材料只用于完善机制、实例、边界与验证证据，并保留公开来源。
- 公开正文不写个人学习进度、私有路径与内部任务信息。
