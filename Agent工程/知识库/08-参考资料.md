# 参考资料

## 核心材料

[Datawhale Hello-Agents](https://github.com/datawhalechina/hello-agents)《从零开始构建智能体》是本板块的核心材料，各知识点正文中所说的“教材”都指它。

- **引用版本**：主分支提交 `4f7682c`（2026-09-04）。教材后续更新可能改变小节编号，引用以该版本为准。
- **许可**：教材采用知识共享署名-非商业性使用-相同方式共享 4.0 国际许可协议（CC BY-NC-SA 4.0）。本板块以转述与分析为主，引用原文时只摘录必要的短句并注明位置，不转载教材的图片与大段代码。

## 引用写法

- `1.2.2`、`4.2.3`：教材正文的小节号，对应仓库 `docs/chapterN/` 下的中文章节。
- `第 9 章`、`第 4 章引言`：教材正文的整章或章首引言。
- `Extra02`、`Extra09`：教材仓库 `Extra-Chapter/` 下的补充章节，属于社区补充内容，审查程度与正文不同。

## 来源分级与核验标注

知识点末尾用“来源与核验”表格列出关键结论的依据，依据分为五级：

| 级别 | 含义 |
|---|---|
| 教材正文 | 教材正文明确讲到的内容 |
| 教材代码分析 | 证据来自教材示例代码，结论是本板块基于代码的分析，教材正文未作此归纳 |
| 社区补充 | 来自教材仓库补充章节的工程经验 |
| 外部公开资料 | 教材之外的公开资料，注明出处 |
| 待核验 | 暂无以上公开依据的结论；需写明推导依据，不作为已验证结论使用 |

正文中属于“待核验”的句子，在句末标注〔待核验〕。未实际运行的实验，不写成可复现的结论。
