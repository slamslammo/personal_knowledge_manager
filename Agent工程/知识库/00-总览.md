# Agent 工程知识梳理

> 以 Datawhale Hello-Agents《从零开始构建智能体》为核心材料（下文统称“教材”，正文中的 1.2.2、第 9 章等编号均指它的章节），按知识之间的逻辑重新组织智能体（Agent）的核心知识。每个知识点说明它解决什么问题、机制如何运转、适用边界在哪里，并标明依据来源与核验状态。

## 知识路线

教材给出了一个简洁的定义：智能体是“在循环中自主调用工具的 LLM”（9.2.2）。它通过智能体循环与环境持续交互：感知新的观察，由大语言模型规划并选择工具，执行行动后再观察环境的变化（1.2.2）。本板块把模型之外、驱动这个循环运行的那层程序统称为**框架**（工程实践中也称 harness）：模型每一轮看到什么、声明如何被解析与执行、何时停止、留下什么记录，都由它决定，见[模型与框架的职责边界](node:responsibility)。

围绕这个定义，本板块把知识分为七个部分，前面的部分为后面的部分提供概念基础：

1. **智能体是什么**：定义、类型与演进脉络，以及大语言模型作为决策核心的能力与局限。
2. **运行机制**：循环如何一步步推进任务，推理与行动有哪些组织范式，任务如何正确地结束。
3. **行动：工具与协议**：智能体靠什么作用于外部世界，工具结果如何交还给模型，跨系统时如何标准化。
4. **信息：上下文、记忆与检索**：模型每一轮能看到什么，跨轮次、跨任务保留什么，外部知识如何按需取回。
5. **构建：框架与多智能体**：模型、工具、上下文与状态如何组织成可运行的系统，单个智能体不足时如何协作。
6. **验证与提升：评估与训练**：如何判断一个智能体或一次改动是变好还是变坏，以及如何持续提升。
7. **应用形态**：上述能力组合成哪些典型应用，各自的关键难点落在哪里。

## 读者前提

本板块面向已具备 Python 与大模型 API 基础、并实际使用过编码类智能体工具（如 Claude Code、Codex）的读者。以下知识点默认读者已经掌握，在图谱中标为“读者前提”，本板块不重复展开；需要补充时请直接阅读教材对应小节（括号中的数字为教材小节号）：

- 智能体循环的基本结构（1.2.2、4.2）；
- 工具调用的基本机制：模型给出调用声明，由程序负责执行（4.2.2、7.5）；
- 上下文工程的基本概念与策略（第 9 章、Extra02）；
- 何时适合使用智能体、何时使用固定工作流（1.4.3）。

## 知识点的阅读方式

每个知识点按四层组织，可以只读到自己需要的深度：

1. **定位**：回答什么问题，在体系中的位置，需要哪些前置知识；
2. **核心解释**：2–5 分钟读完，讲清核心原理与关键结论；
3. **机制深挖**：对照教材代码、设计选项与失效情形展开；
4. **实验与原文**：可复现的实验（如有）与教材原文位置。

知识点末尾统一列出依据来源与核验状态，分级规则与引用写法见[参考资料](node:refs)。
