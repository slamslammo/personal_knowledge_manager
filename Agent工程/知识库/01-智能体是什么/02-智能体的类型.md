# 智能体的类型

## 定位

本节回答：智能体可以从哪些维度分类，各类型的分界问题是什么，以及这些分类对工程选择有什么用。

前置：[智能体的定义与构成](node:agentdef)。

文中的“教材”指核心材料 Hello-Agents，小节号（如 2.4.5）为教材的章节编号；引用写法与版本见[参考资料](node:refs)。

## 核心解释

教材从三个互补的维度对智能体分类（1.1.3）。三个维度回答的是不同问题，可以叠加使用：

| 维度 | 谱系 | 分界问题 |
|---|---|---|
| 内部决策架构 | 反应式 → 模型式 → 基于目标 → 基于效用；学习能力是可叠加的元能力 | 决策依据是当前感知、内部状态、目标，还是多目标之间的权衡 |
| 时间与反应性 | 反应式 / 规划式 / 混合式 | 先行动还是先思考 |
| 知识表示 | 亚符号 / 符号 / 神经符号 | 决策依据是分布式的模式，还是可检查的符号 |

**内部决策架构**沿着一条能力阶梯展开（1.1.1）：简单反射智能体只做“条件—动作”的直接映射，不具备记忆与预测；基于模型的反射智能体引入世界模型，用于追踪无法被直接感知的部分；基于目标的智能体主动选择能导向目标的行动；基于效用的智能体为不同状态赋予效用值，在相互冲突的目标之间权衡。学习能力可以叠加在以上任何一类之上。

**时间与反应性**揭示的是速度与最优解之间的权衡（1.1.3）。反应式智能体延迟低、开销小，代价是“短视”，容易陷入局部最优；规划式智能体先系统地探索可能性再行动，优势是战略性与远见，代价是时间与计算成本，在快速变化的环境中可能错过时机；混合式结合两者，经典做法是分层——底层快速反应，高层审慎规划。

**知识表示**是更根本的一个维度（1.1.3）。亚符号（连接主义）把知识以统计模式分布在网络中，擅长模式识别、对噪声鲁棒，但是黑箱、逻辑推理弱，并会产生看似合理却事实错误的幻觉；符号主义把知识表示为人类可读的符号与规则，透明可追溯，但在现实世界的模糊与例外面前脆弱，存在知识获取瓶颈；神经符号试图结合两者，教材用《思考，快与慢》中的系统 1 与系统 2 作类比。

教材对大语言模型智能体在这两个维度上的定位很明确：

- 在时间维度上，它是混合式的一种新形态。“思考”是审议过程，“行动”与“观察”是反应过程，于是一个需要长远规划的大任务，被拆成一连串“规划—反应”的微循环（1.1.3）。
- 在知识表示维度上，它是神经符号主义的实践范例：内核是一个巨大的神经网络，工作时又会生成思想、计划、接口调用这些明确、可操作的符号（1.1.3）。

这三个维度对应三个具体的设计问题：要不要维护对话之外的内部状态；一步一看还是先整体规划；决策过程要不要留下可检查的中间产物〔待核验〕。本板块把它们分别落在[任务状态](node:taskstate)、[运行机制](node:mechanism)中的范式选择，以及[评输出与评轨迹](node:outputtrajectory)。

## 机制深挖

### 教材范式在时间维度上的位置

教材没有把第 4 章的三种范式与 1.1.3 的分类维度对应起来，下表的归类由本板块整理〔待核验〕：

| 范式 | 在时间维度上的位置 | 依据 |
|---|---|---|
| ReAct | 偏反应：“走一步，看一步”，用每一步的观察调整下一步 | 4.2.4 |
| Plan-and-Solve | 偏规划：先生成完整计划，再由执行器逐步完成 | 4.3 |
| Reflection | 在产出之后追加审议：执行—反思—优化 | 4.4 |

### 分类是谱系，不是互斥标签

教材把学习能力称为“可赋予上述所有类型的元能力”（1.1.3），这说明这些类别并不互斥。同一个大语言模型智能体，在不同任务上既可以偏反应也可以偏规划，取决于框架采用哪种范式、提示词如何约定，而不取决于模型本身。换框架会改变它在时间维度上的位置，这一点见[模型与框架的职责边界](node:responsibility)。

### 亚符号的局限在智能体里没有消失

教材在描述亚符号系统时列出的两个弱点——不透明、会产生看似合理却事实错误的幻觉（1.1.3）——正是大语言模型作为决策核心时要处理的问题。智能体生成的思想、计划与调用是可检查的符号，但产生它们的过程仍然不透明，见[大语言模型作为决策核心](node:llmcore)。
