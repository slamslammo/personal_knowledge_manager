# 智能体是什么

本部分回答：什么样的系统算智能体，它与一次性调用大语言模型、预设流程的工作流有什么不同，又是从哪里演进而来。后续各部分讨论的运行机制、工具、信息与评估，都建立在这里的定义之上。

## 主线

传统智能体从依赖“条件—动作”规则的反射智能体起步，为了应对当前感知不足以支撑决策的环境，逐步发展出更复杂的决策架构（1.1.1）；[智能体的类型](node:agenttypes)沿三个维度梳理了这条谱系。大语言模型带来的变化在于，循环中的“思考”环节可以由模型用自然语言完成规划与工具选择（1.2.2），智能体因此能够处理事先无法穷举规则的开放任务——[智能体的定义与构成](node:agentdef)给出这套结构的完整定义，[从符号主义到大模型驱动](node:history)说明它是怎样演变到这一步的。

这种能力的边界也来自大语言模型本身。模型幻觉等局限（3.3）不会因为加上循环与工具而自动消失，而会在运行机制、信息管理与评估中以不同形式出现〔待核验〕；[大语言模型作为决策核心](node:llmcore)集中讨论这些能力与局限的来源。理解智能体，既要知道它能做什么，也要知道这些局限从哪里来。
