# 应用形态

本部分回答：前六部分的能力组合起来，形成了哪些典型的智能体应用，不同形态的关键难点分别落在哪里。

文中的“教材”指核心材料 Hello-Agents，小节号（如 2.4.5）为教材的章节编号；引用写法与版本见[参考资料](node:refs)。

## 知识点

| 知识点 | 回答的问题 | 教材依据 | 状态 |
|---|---|---|---|
| 协作模式 | 智能体作为开发者工具与作为自主协作者时，人与智能体如何分工 | 1.4.1、1.4.2 | 未展开 |
| 深度研究智能体 | 如何用任务清单驱动检索、总结与报告生成 | 第 14 章 | 未展开 |

| 编码智能体 | 读写代码库的智能体在工具设计、上下文与可观测性上面临哪些特殊问题 | Extra09 | 未展开 |
| GUI 与 Web 智能体 | 通过屏幕或网页界面操作的智能体如何感知界面、执行操作 | Extra06、Extra11 | 未展开 |

## 主线

应用形态不是新的知识类别，而是前六部分在具体场景中的组合。深度研究智能体以任务清单驱动研究流程，并用结构化笔记保存中间结论（第 14 章）；多智能体应用侧重角色划分与协作流程（13.3）；编码智能体集中暴露了工具粒度、大结果处理与可观测性问题（Extra09）；GUI 与 Web 智能体则需要感知并操作为人设计的界面（Extra06、Extra11）。

阅读案例时，重点是识别它在哪个环节做了什么取舍，并回到对应部分理解背后的机制，而不是复述实现细节。
