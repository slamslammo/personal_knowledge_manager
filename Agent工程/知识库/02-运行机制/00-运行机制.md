# 运行机制：循环、范式与停止

本部分回答：智能体如何一步步推进任务，推理与行动有哪些组织方式，以及任务如何正确地结束。

## 主线

智能体循环是智能体的基本运行单位。ReAct、Plan-and-Solve、Reflection 是在循环之上组织推理与行动的三种典型方式：ReAct “走一步，看一步”，根据每一步的观察调整下一步（4.2.4）；Plan-and-Solve 先生成完整计划，再由执行器逐步完成（4.3）；Reflection 在得到结果后进行审查与迭代优化（4.4）。

无论采用哪种范式，循环都必须能正确地结束。教材把步数上限称为防止智能体陷入无限循环的“安全阀”（4.2.3），但步数上限只是兜底。[停止条件设计](node:stopcond)回答“应当在什么条件下停”，[终止判定的漏判](node:terminate)回答“实际运行中为什么会停错”，两者是同一个问题的设计面与失效面。
