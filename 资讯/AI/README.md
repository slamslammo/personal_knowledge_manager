# AI 资讯

`资讯/` 下的 AI 板块：按周汇总 AI 关键内容，按周报、月报、季报长期积累，便于按时间和主题回溯。当前由 WorkBuddy 本机手动触发，尚未启用定时调度。

与其他知识板块不同，本板块以资讯为主，允许大量外链，每条资讯都附原始链接供深入阅读。周报保留资讯原貌，月报和季报以分析和判断为主。每期报告开头带元数据（主题、机构、项目），可按内容检索。

## 内容

| 产出 | 路径（`AI/数据/` 下） | 频率 |
| --- | --- | --- |
| 周报 | `周报/{ISO 周年}/{WEEK}.md` | 每周一 |
| 月报 | `月报/{年}/{年}-{MM}.md` | 每月最后一周结束后的周一 |
| 季报 | `季报/{年}/{年}-Q{N}.md` | 每季度最后一周结束后的周一 |
| 榜单数据 | `github-weekly/{WEEK}.json` | 每周一 |
| 运行记录 | `运行记录/{WEEK}.json` | 每次运行（协调锁与执行记录，用于事后定位问题） |

周报依次为：本周概览、洞察、新发布与技术 Top 5、GitHub AI 项目热度 Top 5、传播文章 Top 5、热点话题 Top 5。

> 运行期的执行明细 `trace.jsonl` 留在 `/tmp/ai-weekly/`，不入库；正式留痕是 `数据/运行记录/{WEEK}.json` 的 `events` 字段（由 `coord.py` 合并后随状态文件推送到 `main`），可用 `工程/scripts/trace_view.py --week <WEEK>` 还原时间线。
