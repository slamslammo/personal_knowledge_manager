# AI 资讯

本板块收录有原文可查的 AI 资讯。周报记录一周的发布、项目与讨论，月报和季报据此分析跨期变化。已发布的报告全文在 GitHub，飞书年度表按期间展示摘要并链接到正文。

## 内容

| 产出 | 在哪里看 | 阅读提示 |
| --- | --- | --- |
| 周报 | [数据/周报](数据/周报/) | 按 ISO 周查概览、洞察、新发布与技术、GitHub 热门项目、传播文章和热点话题。 |
| 月报 | [数据/月报](数据/月报/) | 正式月报汇总周四落在该月的各份周报，跨月事件保留原日期。 |
| 季报 | [数据/季报](数据/季报/) | 正式季报综合三份月报，依据整个季度的周榜明细看项目热度。 |
| 榜单与运行记录 | [GitHub 周榜](数据/github-weekly/) · [周运行记录](数据/运行记录/) | 可分别核对各期排名数据与发布状态。 |

2026 年 1–9 月及 Q1–Q3 的报告是基于当期可追溯来源撰写的历史专题。阅读时可从元数据区分专题回顾和基于正式周报生成的报告。[口径与覆盖](文档/方案.md)
