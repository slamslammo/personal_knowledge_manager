# AI 资讯文档

本目录保存 AI 资讯项目的现行设计、开发与运行指南，以及功能迭代的计划和决策记录。了解项目先读方案，查某项功能何时提出、完成到哪一步，从版本规划进入。

| 想了解什么 | 去哪里看 |
| --- | --- |
| 周报、月报、季报如何产生，历史专题和飞书年度表怎样使用 | [方案](方案.md)。开头列出最近的关键变更，正文说明当前规则。 |
| 已交付哪些功能，接下来做什么 | [版本规划](版本规划.md)。每个里程碑链接到设计或交付证据。 |
| 某次迭代为什么这样选，有什么验证或遗留问题 | [提案与复盘](提案/README.md)。例如[为什么保留历史专题、改用年度表](提案/2026-11-24-年度资讯档案展示规范与历史专题.md)。 |
| 改哪个模块，如何测试、评审和合并 | [工程结构](工程结构.md)定位代码，[工程 README](../工程/README.md)提供本地测试命令，[开发规范](开发规范.md)说明变更流程。 |
| 在哪里运行，如何授权、验收与补交付 | [部署指南](部署指南.md)。实际操作按[周报](../工程/prompts/weekly.md)、[月报](../工程/prompts/monthly.md)或[季报](../工程/prompts/quarterly.md)手册执行。 |

阅读已发布的周报、月报和季报，直接进入[数据目录](../数据/)。
