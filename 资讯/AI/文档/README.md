# AI 资讯文档

本目录保存 AI 周报的内容规则、开发约定、部署说明和变更记录，供开发、评审和排障时查阅。按手头的问题选读下表中的文件。

| 文件或目录 | 职责与用法 |
| --- | --- |
| [方案.md](方案.md) | 周报规格。确定周报写什么、数据如何入选、怎样判断内容合格。改板块或榜单口径先查这里。 |
| [开发规范.md](开发规范.md) | 工程开发与协作约定。改脚本或评审 PR 时，查实现约定、哪些变更需要提案、如何测试和合并。 |
| [部署指南.md](部署指南.md) | 运行环境、授权、验收和故障恢复。需要部署，或 Git 已发布但飞书交付失败时，查这里。 |
| [版本规划.md](版本规划.md) | 当前待办与候选方向，用来决定下一轮做什么。 |
| [提案/](提案/README.md) | 对具体变更的取舍、验收结论和历史复盘。可从目录里的模板起草新提案。 |

第一次接手代码，从[工程目录](../工程/README.md)看核心脚本、依赖和本地测试。执行一次周报查[执行手册](../工程/prompts/weekly.md)，查看已有周报和记录到[数据目录](../数据/)。
