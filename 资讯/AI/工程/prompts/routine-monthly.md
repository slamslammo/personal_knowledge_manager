1. 同步到远端最新的 `main`（本次指令带 `TEST_RUN=1` 时留在当前分支），读取 `资讯/AI/工程/prompts/monthly.md`，确认第一行是 `<!-- task: ai-weekly-monthly -->`，然后按它执行。
2. 本次指令里的参数（`--month YYYY-MM`）原样交给执行手册处理；不带参数时按北京时间推算上一个已结束的月报。

## 无法生成月报报告时也要通知
执行手册不存在、第一行不对，或任何一步出现无法恢复的错误导致无法生成报告时，都必须通知我（优先 `python3 资讯/AI/工程/core/feishu_sync.py notify --file <通知文件>` 以飞书应用身份发送；平台没有 lark-cli 或预检为 no_notify/off 时，用你所在平台的通知方式），纯文本：
- 首句：`【AI 月报 YYYY-MM｜失败】<原因>。`；期间无法确定时写 `【AI 月报｜失败】<原因>。`
- 之后写清停在哪一步、已经完成了什么。
- 测试模式下不发通知，把同样的内容在最后原样输出。

成功通知由 `period_report.py` 生成并以飞书 Markdown 发送：标题只留期间、要点加粗并用 `1）` 编号，不贴原文 URL 与 GitHub 全文链接，尾部给年度表当期记录直达链接。你无需手写成功通知，也不要在通知里另附全文链接。
