# AI 季报 · 2026-Q1（专题回顾版）

> 本季无正式周报/榜单/月报，三份月报均为专题回顾版。正文依据 HN 时间窗检索（1/2/3 月 AI 相关高分帖 16/30/22 条）与官方发布记录；GitHub 期间新增 star 不可回溯，不写 star 数字。B 级归纳需人工确认。

## 季度主线

1. **agent 从概念走向可执行工具**：1 月 Cowork / CLI agents 让 agent 进入工作与自托管场景；2 月 Opus 4.6 agent teams 构建 C 编译器，显示多 agent 分工协作的工程能力；3 月 OpenCode 把 coding agent 开源化。三个月构成"场景扩展 → 工程协作 → 开源化"的连续链条。（B 级归纳，依据：[Cowork](https://news.ycombinator.com/item?id=46593022)、[agent teams](https://www.anthropic.com/engineering/building-c-compiler)、[OpenCode](https://news.ycombinator.com/item?id=47460525)）
2. **个人助理形态出现但未定型**：1/26 Clawdbot 开源个人助理、2/1 NanoClaw、2/21 "Claws are now a new layer on top of LLM agents"；同期出现 ClawHub 恶意 skill（2/5）。`muse` 个人助理在 Q1 无一手证据，属 Q4 线索，不回写本季。（B 级归纳）
3. **agent 自主行为引发治理反弹**：2/12 "AI agent 发攻击文章"、3/30 Copilot PR 插广告、3/11 HN 禁止 AI 生成评论（HN 4229，本季最高分）。三个独立事件指向同一张力：agent 自主行动与公共/工程场景的边界。（B 级归纳）

## 开源与产业趋势

- **开源 coding agent 进入主流讨论**：OpenCode（3/20）是本季开源侧最高热度条目；Claude Code 200 行复现（1/8）显示 agent 循环被社区拆解学习。
- **GitHub 榜不可用**：本季无周榜存档、stargazers 与 Trendshift 历史增量不可回溯，不生成 star 榜、不写名次；仅用 HN 分数与官方发布记录作可回溯信号。
- **工具可信度成为产业议题**：Claude Code 源码泄露（3/31, HN 2095）、Copilot PR 广告（3/30, HN 1606）、ClawHub 恶意 skill（2/5, HN 334）三例说明 agent 生态扩张伴随供应链与中立性风险。

1. Claw 系个人助理是否形成稳定产品形态（本季只是出现，未定型）；`muse` 类个人助理是否有 Q2 一手证据。

3. HN 禁止 AI 生成评论后，其他平台是否跟进；agent 自主对外行动的边界是否形成惯例。
4. 模型密集发布节奏是否延续（本季 2 月 6 个、3 月 1 个）。
