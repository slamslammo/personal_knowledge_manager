# AI 周报 · 2026-W45（11/2–11/8）（回溯版）

## ① 本周概览

- **开放权重**：Moonshot AI 放出 Kimi K3.1 Pro 完整权重，腾讯发布 Hy4 并承诺后续公开权重。
- **生成媒体**：OpenAI Images 2.6 加入 GIF 与标注式编辑，Google Omni 1.2 Flash 把单段视频延至 15 秒。
- **智能体工具**：GitHub 前五名都是逆向、复刻、编程与桌面控制类工具，rea 本周新增 25,051 star。

## 洞察

### 洞察 1：本周工具竞争的焦点是「智能体能碰什么」，不是模型分数

- **依据**：③ rea 把二进制与运行时行为交给智能体，agent-desktop 直接读无障碍树操作桌面，dsh-superagent 常驻仓库接活；④ Claude Code 与 Postman 两个问题报告都在讨论工具是否越过了用户同意边界。
- **必读**：[Postman 问题报告](https://github.com/postmanlabs/postman-app-support/issues/14370)：看桌面应用如何改写其他智能体的配置；[agent-desktop 深度解读](https://flaviocopes.com/agent-desktop/)：看无障碍树方案的权限前提与失败回执设计。

### 洞察 2：可编辑、可复核正在成为发布质量的硬指标

- **依据**：② Images 2.6 与 Omni 1.2 Flash 都强调多轮编辑而非一次生成，Kimi 权重允许外部检查；④ 权重空间编程的原实验与质疑文章并列传播，独立审计把「改权重有效」与「读权重成立」拆开判断。
- **必读**：[权重空间编程审计](https://aitecharchive.com/articles/weight-space-programming-qwen-weight-edit-audit)：看可复现的编辑结论与未通过的读取结论如何区分；[Anthropic 可证明推理](https://www.anthropic.com/research/provable-inference)：看用密码学承诺绑定模型与回应的代价。

## ② 新发布与技术 Top 5

### OpenAI 发布 Images 2.6

- **是什么**：11 月 4 日在 ChatGPT、Codex 和 API 推出新图像生成与编辑模型，API 分 Flare 与 Sunburst 两款。
- **新在哪里**：官方称生成速度提升 50%，新增 GIF 制作、标注式编辑与 SVG 导出；速度属厂商自报。
- **对谁有影响**：需要反复修改品牌素材、角色和产品图的设计团队与开发者。
- **原文**：[OpenAI 公告](https://openai.com/index/introducing-images-2-6/)；[HN 讨论 384 分](https://news.ycombinator.com/item?id=50372945)。

### Google 推出 Gemini Omni 1.2 Flash

- **是什么**：11 月 5 日发布新一代视频生成模型，在 Gemini API 与 Google Cloud 正式可用。
- **新在哪里**：官方称单段视频从 10 秒延长至 15 秒，支持多轮对话式编辑，720p 定价比 1.1 低 30%；效果以公告为准。
- **对谁有影响**：制作广告、演示和短视频的创作者与开发者。
- **原文**：[Google 公告](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/)；[HN 讨论 369 分](https://news.ycombinator.com/item?id=50392118)。

### Moonshot AI 开放 Kimi K3.1 Pro 权重

- **是什么**：11 月 4 日在 Hugging Face 提供完整权重，模型此前已在 Kimi 产品与 API 上线。
- **新在哪里**：官方模型卡称 2.8 万亿总参数、1040 亿激活参数的多模态 MoE，约 100 万 token 上下文；性能为厂商自评。
- **对谁有影响**：有足够算力、希望自行评测或部署的研究者和企业；使用须核对专门许可。
- **原文**：[Moonshot AI 模型卡](https://huggingface.co/moonshotai/Kimi-K3.1-Pro)；[HN 讨论 641 分](https://news.ycombinator.com/item?id=50366999)。

### 腾讯发布 Hy4

- **是什么**：11 月 4 日发布新一代模型，增加视觉理解并改善长上下文与智能体任务。
- **新在哪里**：腾讯宣布 API 经第三方平台提供，模型权重与系统卡将随后发布；不能把「计划开放」写成「已开放」。
- **对谁有影响**：需要多模态和工具调用能力的开发者；自部署需等待权重。
- **原文**：[腾讯研究页](https://hy.tencent.ai/research/hy4)；[HN 讨论 294 分](https://news.ycombinator.com/item?id=50365780)。

### Anthropic 公布可证明推理原型 FlashProve

- **是什么**：11 月 2 日发布 zkSNARK 原型，让服务方承诺模型并证明每个回应由该模型产生。
- **新在哪里**：官方报告单张 H100 约 110 token/秒出证明，1024 token 请求约 19 MB；开销仍是直接推理的 70–95 倍。
- **对谁有影响**：第三方评测、路由服务付费方与合规审计；当前只覆盖整数模型与贪心解码。
- **原文**：[Anthropic 研究页](https://www.anthropic.com/research/provable-inference)；[HN 讨论 241 分](https://news.ycombinator.com/item?id=50368626)。
