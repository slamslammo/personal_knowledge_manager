# AI 周报 · 2026-W47（11/16–11/22）

## ① 本周概览

- **旗舰模型**：OpenAI 发布 GPT‑6.2 Astra/Sol，Google 推出 Gemini 4 Neon，均主打专业工作流与更低成本。
- **资本里程碑**：Anthropic 以 83 美元/股登陆纳斯达克，募资约 935 亿美元，成为美股史上最大 IPO。
- **攻防工具**：AI 自主渗透框架 ARTEX 与漏洞猎手技能包 Claude-BugHunter 冲上 GitHub 周榜前 3。
- **隐私争议**：Signal 默认拦截手机系统 AI 代理读取聊天；Windows 11 被曝记录用户使用哪些编程代理。
- **研究进展**：Claude 解决两个黑洞物理开放问题，27B 开源模型实现无梯度自我权重改写。

## 洞察

### 洞察 1：前沿模型竞争从"能力上限"转向"单位任务成本"

- **依据**：② 中 GPT‑6.2 Astra 比上代便宜约三分之一、Gemini 4 Neon 单任务成本降 32%、微软七款 MAI 以约 5% 的价格对标 Claude Opus 5.5；③ 中 t3code 与免费模型插件 dsh-our-free-model 的走红，也说明开发者对成本与可控性的敏感。
- **必读**：[OpenAI GPT‑6.2 发布说明](https://openai.com/index/introducing-gpt-6-2-astra-sol/)：看旗舰模型如何在基准持平下压低单任务成本；[微软 Ignite 七款模型](https://microsoft.ai/news/microsoft-ignite-2026/)：看大厂如何用分工模型线打性价比战。

### 洞察 2：AI 代理工具链正在把攻防门槛同时拉低

- **依据**：③ 的 ARTEX（FBI 警告已被用于真实入侵）、Claude-BugHunter（681 份披露报告蒸馏成技能包）、REA（把逆向工具接入 Agent）；④ 的 Windows 11 遥测与 ⑤ 的 Signal 拦截，说明系统层也在被动回应。
- **必读**：[Signal 官方博客](https://signal.org/blog/protecting-your-privacy/)：理解 OS 级 AI 代理如何绕开端到端加密；[TechCrunch 对 ARTEX 的报道](https://techcrunch.com/2026/11/16/fbi-says-artex-ai-open-source-hacking-tool-used-to-breach-networks-in-under-three-hours/)：看自动化攻击的真实门槛。

### 洞察 3：AI 开始产出可机器验证的科研结果

- **依据**：② 中 Claude 用多智能体解决两个黑洞物理开放问题，其中一项经 Lean 形式化验证；① 提到的自改写权重论文在 490 道未见题上把 27B 模型准确率从 57.2% 提升到 63.8%。
- **必读**：[Anthropic 研究页](https://www.anthropic.com/research/claude-black-hole-physics)：看多智能体如何协作完成理论物理推导；[arXiv 自改写权重论文](https://arxiv.org/abs/2611.21885)：看无梯度修改权重的方法与边界。

## ② 新发布与技术 Top 5

### OpenAI 发布 GPT‑6.2 Astra 与 Sol

- **是什么**：Astra 面向复杂专业与科研任务，Sol 面向日常多步工作流；已在 ChatGPT Work、Codex 与 API 上线。
- **新在哪里**：Astra 在 Agents' Last Exam 比 GPT‑6 Astra 高 5.2 分、成本不到三分之一；API 输入输出价格降 20%，缓存输入降 60%。
- **对谁有影响**：企业与开发者可用更低成本跑长程智能体任务；高风险网络安全能力被收紧。
- **原文**：[Introducing GPT‑6.2 Astra and Sol](https://openai.com/index/introducing-gpt-6-2-astra-sol/)；[HN 讨论 1347 分](https://news.ycombinator.com/item?id=50535230)

### Google 发布 Gemini 4 Neon

- **是什么**：面向复杂编程、分析与企业工作流的旗舰模型，支持 100 万 token 上下文。
- **新在哪里**：xhigh 档在 Artificial Analysis 智能指数列第 3、得分 61；内部评估质量追平更大的 Carbon、速度 3 倍、成本 60%。
- **对谁有影响**：Pro/Ultra 订阅者与企业 API 用户可直接在 Gemini 应用与 Google Antigravity 中使用。
- **原文**：[Introducing Gemini 4 Neon](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-neon/)；[HN 讨论 1071 分](https://news.ycombinator.com/item?id=50552424)

### 阿里巴巴发布 Qwen4-Max

- **是什么**：千问系列旗舰，总参数 2.4 万亿、每 token 激活 710 亿，具备原生视觉与 100 万上下文。
- **新在哪里**：Work360 评测优于上代，高强度推理下 token 用量减 35%、单任务成本降约六成；中小尺寸模型将陆续开源。
- **对谁有影响**：需要中文、视觉与智能体工作流的团队；API 已上线千问 AI 平台。
- **原文**：[Qwen4-Max 官方公告](https://qwen.ai/blog?id=qwen4-max)、[阿里巴巴集团公告](https://www.alibabagroup.com/document-2060139246777270272)；[HN 讨论 884 分](https://news.ycombinator.com/item?id=50513215)

### 微软在 Ignite 一次发布七款 MAI 模型

- **是什么**：覆盖编程、安全、图像、实时语音、转写与决策路由的七款自研模型，Maia 200 已投产。
- **新在哪里**：MAI Code 2 在四项企业编程基准达 GPT‑6.1 Sol 约 98% 质量、约 40% 价格；Cyber 2 Flash 单任务成本不到 GPT‑6 Astra 的 2%。
- **对谁有影响**：GitHub Copilot、Foundry 用户可按需替换部分外部模型；对比数字均为微软自评，尚缺第三方复核。
- **原文**：[Seven new models at scalable price-performance](https://microsoft.ai/news/microsoft-ignite-2026/)；[HN 讨论 607 分](https://news.ycombinator.com/item?id=50548021)

### Claude 解决两个黑洞物理开放问题

- **是什么**：Anthropic 报告 Claude Fable 5.2 完成搁置 20 余年的 Hawking‑Page 相变计算，并给出模自举法的精确上限。
- **新在哪里**：22 个课题由多个智能体后台并行研究约六周，结果经 Lean 形式化验证，论文由模型起草后由物理学家逐项核对。
- **对谁有影响**：科研自动化与可验证推理的边界；两项结果均不描述真实宇宙，也无直接应用。
- **原文**：[Claude solves two open problems in the physics of black holes](https://www.anthropic.com/research/claude-black-hole-physics)；[HN 讨论 580 分](https://news.ycombinator.com/item?id=50563148)

### 4. [pingdotgg/t3code](https://github.com/pingdotgg/t3code)

- **我们的判断**：适合同时跑多个编码代理、需要远程审批的开发者；项目自述仍早期且暂不接收大功能外部贡献，连接远程主机时注意权限边界。
