# AI 周报 · 2026-W46（11/9–11/15）（回溯版）

## ① 本周概览

- **模型与验证**：Anthropic 发 Claude Fable 5.2/Mythos 5.2（编程与科研能力提升），DeepMind 用 AlphaProof Code 在四周内机器验证 Signal 核心协议代码；Claude 从哥德尔笔记提取 663 条命题，约 400 条经 Coq 验证。
- **agent 形态分化**：Google 发 Gemini 4 Hydrogen 与 Orchestrator（会话中 Carbon/Hydrogen 动态切换）、Gemini Decision 1 决策 API；Meta 发低成本 Muse Ember；苹果测试本地推理应用 Harbor。
- **agent 边界收紧**：美联航成为美国首家禁止第三方 AI 代理代订机票的航司，理由是账户安全与 FAA/DOT 合规；高盛把 Claude Code 等编码工具限制给工程师。
- **产业震荡**：Anthropic 以 ANT 上市，首日涨 17% 次日回落；黄仁勋辞任英伟达 CEO；媒体披露英伟达向 AI 初创注资以消化 GPU 产能，市场对 AI 资本开支回报的质疑升温。

## 洞察

### 洞察 1：形式化验证成为 AI 能力的可信出口
- **依据**：AlphaProof Code 用 Lean 内核逐条检查 agent 生成的证明；哥德尔笔记提取的 663 条命题中约 50 条被 Coq 判为错；Claude Code 团队让审查规则位于 PR 之外、三次失败转人工。
- **必读**：[AlphaProof Code](https://deepmind.google/blog/introducing-alphaproof-code/)：看"AI 提出、机器判定"如何替代对模型输出的信任。

### 洞察 2：agent 的形态与成本被拆成可选择的层
- **依据**：Orchestrator 在会话中按阶段切换 Carbon/Hydrogen；Decision 1 把路由/判定做成便宜快速端点；Muse Ember 定位高频子任务，均与大模型分工。
- **必读**：[Gemini 4 Hydrogen and Orchestrator](https://antigravity.google/blog/gemini-4-hydrogen-in-google-antigravity/)：理解模型选择从"一次路由"变为"轨迹内动态切换"。

### 洞察 3：自主 agent 的边界由行业规则而非能力决定
- **依据**：美联航以账户安全与 FAA/DOT 合规为由禁第三方代理订票；高盛限制 Claude Code 给工程师；Gemini 个人版把连接应用数据交人工审核引发反弹。
- **必读**：[United 官方说明](https://www.united.com/en/us/fly/help-center/digital-trust-center/artificial-intelligence/third-party-ai-agents.html)：看行业如何把 agent 风险落到具体服务条款。

## ② 新发布与技术 Top 5

### Anthropic 发布 Claude Fable 5.2 与 Mythos 5.2
- **是什么**：同一底层模型的两种配置，Fable 面向普通用户并带网络安全/生物安全限制，Mythos 面向通过审核的安全与生命科学研究机构。
- **新在哪里**：输出速度较上代最高提升 30%，API 价格下调 20%（每百万输入 8 美元、输出 40 美元）；FrontierCode 2.0 从 32.4% 升至 49.1%；演示了 1000 个 agent 协作、30 小时完成费马大定理既有证明的形式化验证。
- **对谁有影响**：需要长程工程与科研任务的团队；厂商跑分与演示需独立复核，不能等同于普遍能力。
- **原文**：[Claude Fable 5.2 and Mythos 5.2](https://www.anthropic.com/claude-fable-and-mythos-5-2)；[HN 讨论 1000 分](https://news.ycombinator.com/item?id=50429906)

### DeepMind 发布 AlphaProof Code 验证 Signal 核心代码
- **是什么**：多 agent 形式化验证框架，人类写规格、Gemini Carbon agent 生成 Lean 证明、Lean 内核逐条检查。
- **新在哪里**：四周内生成约 630 万行机器检查的 Lean 证明，覆盖 libsignal 的 PQXDH 握手与 Triple Ratchet 的前向保密、认证、后泄露安全；故意注入两个已修复漏洞均能证伪；首次把协议级安全性质连到未修改的机器码。
- **对谁有影响**：安全与密码工程团队；证明只覆盖写明的规格与核心代码，不代表 Signal 全应用无漏洞。
- **原文**：[AlphaProof Code](https://deepmind.google/blog/introducing-alphaproof-code/)；[HN 讨论 679 分](https://news.ycombinator.com/item?id=50439193)

### Google 发布 Gemini 4 Hydrogen 与 Orchestrator
- **是什么**：面向日常编码与 agent 执行的快速模型，以及在单次会话中按任务阶段在 Carbon 与 Hydrogen 间动态切换的 Orchestrator 选项。
- **新在哪里**：Orchestrator 在 Terminal-Bench 4.1 上接近 Carbon 成功率、配额少耗 24%、快 19%（Google 自报）；Hydrogen 在 Artificial Analysis 智能指数得 51（xhigh 54）、支持四档思考深度。
- **对谁有影响**：关注 agent 成本与延迟的开发者；静态路由在长程任务中失效是 Orchestrator 要解决的问题。
- **原文**：[Gemini 4 Hydrogen](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen/)；[Orchestrator](https://antigravity.google/blog/gemini-4-hydrogen-in-google-antigravity/)；[HN 讨论](https://news.ycombinator.com/item?id=50471431)

### Google 发布 Gemini Decision 1 与 Decisions API
- **是什么**：不做逐 token 生成的决策模型，对共享多模态输入上的封闭问题直接返回概率与置信度。
- **新在哪里**：单次请求最多 1000 个独立问题、256K token 上下文，支持是/否、多选（最多 255 项）与评分三型；端到端延迟 150–250ms；输入每百万 token 0.10 美元、输出免费。
- **对谁有影响**：需要路由、策略检查、批量判定的 agent 系统；置信度可用于把模糊结果转人工。
- **原文**：[Gemini Decisions API](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/)；[HN 讨论](https://news.ycombinator.com/item?id=50456791)

### Anthropic 启动 IPO
- **是什么**：以代码 ANT 在纳斯达克挂牌，S-1 于 10/26 公开；本周进入路演与定价窗口。
- **新在哪里**：发行 8.25 亿股 A 类普通股，发行价区间 70–78 美元，另有 260 亿美元私募配售；目标估值报道区间 1.5–2 万亿美元，尚未获公司确认。
- **对谁有影响**：关注 AI 公司估值与算力承诺的投资者；招股书自述生成代码可能触发开源许可证义务。
- **原文**：[Anthropic IPO](https://ipo.anthropic.com/us/)；[HN 讨论 1009 分](https://news.ycombinator.com/item?id=50465829)
