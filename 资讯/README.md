# 资讯

本目录按主题组织资讯项目。每个板块独立维护信息源、报告和发布流程，可以包含周、月、季等多种任务。

## 目录约定

| 位置 | 职责 |
| --- | --- |
| `README.md` | 介绍本板块的内容、产物和阅读入口。 |
| `工程/` | 存放任务会执行或加载的脚本、配置、提示词、模板与依赖清单。 |
| `文档/` | 保存现行设计、开发与部署指南、版本规划和提案。 |
| `数据/` | 存放已发布的报告、榜单与运行记录。临时材料按工程的工作目录约定保存。 |

## 当前与规划

| 板块 | 进展 |
| --- | --- |
| [AI 资讯](AI/README.md) | 周报收集资讯，月报和季报综合分析。全文保存在 GitHub，飞书年度表提供摘要和正文链接。当前运行方式见[部署指南](AI/文档/部署指南.md)。 |
| 财经、股票 | 候选板块，分别维护各自的数据源和选题范围。 |

## 新增板块

沿用上表结构。按板块隔离工作目录、运行状态、发布目标和通知接收人，分别配置 CI 路径与调度。工程和文档变更走 PR，任务按本板块授权发布产物。切换运行平台前，确认旧端的任务、重试和交付均已结束。

原 `AI资讯/` 目录在 2026-11-18 迁入 `资讯/AI/`。旧链接的背景及迁移验证见[复盘](AI/文档/提案/2026-11-18-迁移与生产发布复盘.md)。
